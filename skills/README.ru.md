# Каталог глобальных общих навыков

Навыки, размещенные здесь, являются **глобальными навыками по умолчанию**, предоставляемыми wiseflow, и устанавливаются в openclaw/skills/, видимы для **всех crew** (внутренние crew автоматически наследуют, внешние crew должны объявить в DECLARED_SKILLS).

Каждый skill является подкаталогом, содержащим файл SKILL.md.

- Навыки, принадлежащие конкретному crew, должны быть размещены в `addons/officials/crew/<template-id>/skills/` или `crews/<crew-id>/skills/`, не здесь.
- Дополнительные глобальные навыки, предоставляемые через addon, размещаются в `addons/<addon-name>/skills/`, не здесь.

## Глобальные навыки по умолчанию wiseflow

Следующие глобальные навыки не входят в изначальную версию openclaw и предоставляются по умолчанию wiseflow для всех crew:

| Навык | Назначение | Область применения |
|------|-----------|-------------------|
| `smart-search` | Умный поиск: запуск браузера для реального поиска на 40+ платформах, полностью бесплатно, без API Key | все crew |
| `browser-guide` | Рекомендации по использованию браузера: обработка барьеров входа, капч, ленивой загрузки, подписных барьеров | все crew |
| `complex-task` | Разбиение сложных задач и координация многошагового выполнения | все crew; **sales-cs ЗАПРЕЩЕН** |
