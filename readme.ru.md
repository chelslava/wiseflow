## Что такое Wiseflow?

**Wiseflow** (также известный как **openclaw_for_business** или **ofb**) — это многолетная (Multi-Agent) система на базе фреймворка [openclaw](https://github.com/openclaw/openclaw), предназначенная для **реальных бизнес-задач**.

> ### Философия проекта
>
> Openclaw — отличный инструмент, он умеет отправлять письма, писать отчёты, управлять умным домом… но честно говоря, это ли вам нужнее всего?
>
> **Настоящая цель — чтобы ИИ помогал «делать деньги»!**
>
> **Задача этого проекта — не создать «личного ассистента», а собрать команду «цифровых работников», которая будет зарабатывать для вас 7×24.**

Ключевое отличие Wiseflow от vanilla-сборок openclaw и аналогичных решений (включая «креветки» от крупных китайских вендоров): все они позиционируются как **персональные ассистенты** — они хороши для обслуживания вас лично, но не пригодны для обслуживания других людей, а следовательно, не способны зарабатывать деньги.

Wiseflow спроектирован так, чтобы **работать на внешнюю аудиторию**: обрабатывать заявки клиентов, вести продажи, публиковать контент, заниматься PR и бизнес-развитием — и всё это в полностью автоматическом режиме.

## Ключевая концепция: Crew

**Crew** — это специализированный агент, привязанный к определённой рабочей роли, с собственной базой знаний (инструкциями), набором навыков (skills) и личностными настройками.

В оригинальном openclaw все навыки (встроенные и пользовательские) привязываются к одному и тому же агенту, и spawn-субагенты наследуют их все. Это приводит к двум проблемам:

1. **Раздутость**: каждый раунд диалога потребляет больше токенов, модель дольше думает и чаще ошибается.
2. **Опасность**: если агент работает с внешними клиентами, он потенциально может управлять вашим умным домом или подключиться к принтеру. Зачем агенту поддержки клиентов навык подключения к принтеру?

Wiseflow решает эти проблемы с помощью **Crew Template** — для каждой роли (поддержка клиентов, SMM, бухгалтерия) создаётся отдельный шаблон с собственным набором навыков, рабочих инструкций и личностных характеристик.

Crew делятся на два типа:

| Тип | Описание | Управляется |
|-----|----------|-------------|
| **Internal** (внутренние) | Системные роли, работают «внутри компании» | Main Agent |
| **External** (внешние) | Роли, работающие напрямую с клиентами и внешним миром | HRBP |

## Состав команды

### Встроенные Crew (управленческое ядро)

Три встроенных crew являются глобально уникальными, их нельзя удалить. Они составляют «менеджмент» вашей ИИ-компании:

#### Main Agent (Главный агент / «Управляющий»)

- Единая точка входа для всех сообщений пользователя
- Маршрутизирует запросы к соответствующим внутренним crew через `sessions_spawn`
- Управляет жизненным циклом внутренних crew
- Если не находит подходящего crew — либо выполняет задачу сам, либо предлагает нанять нового сотрудника (через HRBP)
- Поддерживает форсированную маршрутизацию: `[Route: @it-engineer] помоги с логами`

#### HRBP (HR-менеджер / «Кадровик»)

- Управляет полным жизненным циклом внешних crew: найм (создание экземпляра), перевод (изменение), увольнение (архивация)
- Периодически сканирует обратную связь от внешних crew и инициирует их улучшение
- Имеет 5 специализированных навыков: `hrbp-recruit`, `hrbp-modify`, `hrbp-remove`, `hrbp-list`, `hrbp-usage`

#### IT Engineer (IT-инженер / «Системный администратор»)

- Берёт на себя развёртывание, обновление, конфигурацию и устранение неисправностей Wiseflow
- После первого развёртывания пользователю больше не нужно руками редактировать конфиги — IT Engineer сделает это сам
- Выполняет плановые проверки состояния системы (heartbeat)
- Говорит на понятном нетехническим пользователям языке

### Официальные Crew («зарабатывающие»)

Эти crew находятся в каталоге `addons/officials/crew/` и предназначены для реального бизнеса:

#### Sales Customer Service (Продающий客服 / Менеджер по продажам)

**Тип**: внешний (external)

Не просто отвечает на вопросы клиентов, а **ведёт к сделке**. Работает 7×24:

- Принимает первую заявку, проводит предпродажную консультацию
- Незаметно для клиента использует sales-скрипты для стимулирования продаж
- Исследует источник прихода клиента, записывает контактную информацию
- **Может выставлять счета и подтверждать оплату**
- Самостоятельно отслеживает отложенные контакты (напомнить через 3 дня)
- Если диалог превышает 20 раундов — автоматически подключает человека
- Ведёт собственную базу клиентов (статус, источник, намерение)

**Специализированные навыки**: `customer-db`, `demo_send`, `exp_invite`, `payment_send`, `proactive-send`

#### Selfmedia Operator (Оператор соцсетей / SMM-менеджер)

**Тип**: внутренний (internal)

Занимается контент-маркетингом для продвижения продуктов и услуг компании:

- Два рабочих режима: исследование темы → создание контента; или черновик → полная статья
- Может запоминать ваши идеи и отрывки материалов, пересылаемые в чат, и использовать их в будущем
- Приоритет иллюстраций: загруженные пользователем → бесплатные стоки → AI-генерация (через siliconflow-img-gen) → повторное использование старых
- Может генерировать короткие видео через `siliconflow-video-gen` (текст→видео или изображение→видео)
- **Автоматически публикует контент** на множестве платформ:
  - Китай: 知乎 (Zhihu), 今日头条 (Toutiao), 掘金 (Juejin)
  - Международные: Medium, Twitter/X, Instagram, TikTok, YouTube
- Все материалы архивирует в `campaign_assets/` с индексом для повторного использования
- Может вызывать дизайнера через `sessions_spawn` для создания иллюстраций

#### Designer (Дизайнер)

**Тип**: внутренний (internal)

Специализируется на визуальном креативе с использованием AI-генерации изображений:

- Генерация изображений по текстовому описанию и модификация изображений (через `siliconflow-img-gen`)
- Создание иллюстраций для статей, постеров, брендовых материалов
- Вызывается другими crew (selfmedia-operator, business-developer) по запросу через `sessions_spawn`

#### Business Developer (Бизнес-разработчик / «Коммерческий директор»)

**Тип**: внутренний (internal)

Активный поиск и привлечение клиентов и партнёров:

- Анализ и оптимизация сети деловых контактов (`connections-optimizer`)
- Массовая рассылка коммерческих предложений по email (`email-ops`)
- Генерация презентаций для инвесторов и переговоров (`pitch-deck`)
- Ранжирование ключевых узлов в социальных графах (`social-graph-ranker`)
- Ежедневный мониторинг конкурентов и сбор отраслевой информации

#### Investor Relations (IR / Связи с инвесторами)

- Поиск инвесторов онлайн и установление холодных контактов
- Заполнение онлайн-заявок и анкет
- Создание качественных презентаций для инвесторов (BP)

## Автономное взаимодействие между Crew

Одно из ключевых нововведений Wiseflow — механизм **автономного сотрудничества между crew**, реализованный через механизм `sessions_spawn` фреймворка OpenClaw.

### Что это значит?

Когда crew сталкивается с проблемой, которую не может решить самостоятельно:

❌ Он **не прекращает работу**  
❌ Он **не просит пользователя о помощи** (это было бы глупо, не правда ли?)  
✅ Он **автономно вызывает подходящий субагент** для решения проблемы  
✅ После решения проблемы **продолжает выполнение исходной задачи**

### Пример рабочего процесса

Представьте, что Selfmedia Operator публикует статью в WeChat и сталкивается с ошибкой:

```
[media-operator] Публикую статью в WeChat...
[media-operator] Ошибка: access_token expired
[media-operator] Анализ: это техническая проблема, вызываю IT Engineer
  └── [it-engineer] Получен запрос: истёк access_token
  └── [it-engineer] Анализ: проблема в механизме обновления токенов
  └── [it-engineer] Исправление: перенастройка обновления токенов
  └── [it-engineer] Результат: проблема решена
[media-operator] Получено решение, продолжаю публикацию
[media-operator] Задача выполнена
```

**С точки зрения пользователя**: весь процесс происходит незаметно — агенты самостоятельно нашли и устранили неисправность.

## Полный цикл автоматизированного привлечения клиентов

Четыре официальных crew-шаблона образуют **сквозной конвейер автоматического привлечения клиентов**:

```
  ┌──────────────────────┐     ┌──────────────────────────┐
  │  Selfmedia Operator  │     │   Business Developer     │
  │  [Контент · Трафик]  │     │ [Активный поиск · Аутрич] │
  │                      │     │                          │
  │  Публикация контента │     │ Анализ связей & Email    │
  │  на всех площадках   │     │ Холодные контакты        │
  └──────────┬───────────┘     └────────────┬─────────────┘
             │          ↑              │        ↑
             │     запрос дизайна      │  запрос дизайна
             │          │              │        │
             │     ┌────┴──────────────┴────┐   │
             │     │       Designer         │   │
             │     │  [Визуальная поддержка] │   │
             │     │  Иллюстрации, постеры   │   │
             │     └────────────────────────┘   │
             │                    │             │
             └────────┬───────────┘             │
                      │                         │
              Трафик и лиды              Трафик и лиды
               ┌──────▼──────────────────────────▼──┐
               │          Sales Customer Service     │
               │          [Конверсия лидов]          │
               │                                     │
               │        7×24 на линии                 │
               │       Ориентация на сделку           │
               │     Выставление счетов               │
               │     Отслеживание намерений           │
               └─────────────────────────────────────┘
```

| Этап | Crew | Задача |
|------|------|--------|
| Контентный маркетинг | Selfmedia Operator | Регулярная публикация контента на всех платформах, привлечение органического трафика |
| Активное привлечение | Business Developer | Анализ сетей контактов, email-рассылки, генерация презентаций, поиск клиентов |
| Визуальная поддержка | Designer | Создание иллюстраций, постеров, брендовых материалов по запросу |
| Конверсия лидов | Sales Customer Service | 7×24 приём и обработка заявок, ведение к сделке, выставление счетов |

## Архитектура и устройство

### Шаблон → Экземпляр

Архитектура Wiseflow построена на принципе **Template → Instance** (шаблон → экземпляр).

- **Шаблон (Template)** — «чертёж» роли: определяет способности, характер, инструменты и рабочие процессы. Хранится в каталоге `crews/` как набор Markdown-файлов.
- **Экземпляр (Instance)** — работающий агент, созданный из шаблона. Имеет уникальный ID, независимую рабочую директорию (`workspace`), собственную память и привязку к каналам связи.

Один шаблон может быть использован для создания нескольких независимых экземпляров (например, два менеджера по продажам для двух разных продуктовых линеек).

### Гибридная маршрутизация сообщений

Система поддерживает два режима работы:

| Режим | Описание |
|-------|----------|
| **A (единый вход)** | Пользователь общается с Main Agent, который распределяет задачи между подчинёнными crew через `sessions_spawn` |
| **B (прямой канал)** | Внешний crew напрямую привязывается к каналу связи (Telegram, WeChat bot и т.д.) — клиенты общаются с ним без посредников |

Один и тот же экземпляр crew может одновременно использоваться в обоих режимах.

## Ключевые технологические улучшения

### Безопасность: трёхуровневая система разрешений

Оригинальный openclaw критикуют за недостаточную безопасность. Wiseflow внедряет трехуровневую систему, где разрешения принудительно исполняются через `exec-approvals.json` и `tools.exec`:

| Уровень | Название | Политика | Применение |
|---------|----------|----------|------------|
| T0 | read-only | `security: deny` — все shell-команды запрещены | Внешние crew (по умолчанию) |
| T1 | basic-shell | `security: allowlist` — только read-only команды | Внутренние crew с низким уровнем риска |
| T2 | dev-tools | `security: allowlist` — инструменты разработки + read-only | Main Agent |
| T3 | admin | `security: full` — полный доступ к системе | IT Engineer, HRBP |

### Антидетектный браузер

Wiseflow заменяет встроенный Playwright в openclaw на **Patchright** — форк Playwright с защитой от обнаружения автоматизации браузера. Это критически важно для:

- Автоматической публикации контента на различных платформах
- Сбора информации с соцсетей и форумов
- Работы Selfmedia Operator

> **Почему Patchright?**  
> Мы исследовали все популярные фреймворки автоматизации браузеров (nodriver, browser-use, agent-browser от Vercel). Все они, при использовании чистого CDP-подключения, оставляют цифровые следы, которые могут быть обнаружены. Только Patchright полностью удаляет CDP-зонды и при этом наследует весь верхнеуровневый API Playwright, что обеспечивает天然ную совместимость с openclaw без установки дополнительных плагинов или MCP.

### Smart Search (интеллектуальный поиск)

Заменяет встроенный `web_search` в openclaw. Три ключевых преимущества:

- **Бесплатный, не требует API-ключа:** не зависит от сторонних поисковых API
- **Мгновенный поиск:** браузер напрямую переходит на целевую страницу или страницу поиска соцсети для получения самых свежих результатов
- **Настраиваемые источники:** пользователь может указать конкретные источники поиска

Поддерживаемые платформы:微博 (Weibo), Twitter/X, Facebook, Bing, Baidu, 知乎 (Zhihu), 百度贴吧 (Baidu Tieba), Amazon, YouTube, GitHub, ArXiv, eBay и другие.

### Addon-механизм и экосистема

Wiseflow **не изменяет исходный код openclaw**. Все улучшения реализованы через аддоны, что гарантирует полную совместимость — Wiseflow без проблем поддерживает установку навыков из **clawhub.ai**.

Официальные аддоны поставляются в `addons/officials/`. Сообщество может разрабатывать и публиковать собственные аддоны (см. `docs/addon_development.md`).

### Awada: приватный канал связи

Awada — это компонент для полностью приватного развёртывания каналов связи. Позволяет:

- Создать собственный изолированный канал для общения с агентами
- Подключиться к сторонним мессенджер-прокси (WeCom business bot и др.)
- Обеспечить полную конфиденциальность данных

### Патчи и улучшения openclaw

Wiseflow применяет несколько патчей к openclaw, автоматически устанавливаемых скриптом `apply-addons.sh`:

| Патч | Описание |
|------|----------|
| `002-disable-web-search-env-var` | Позволяет отключить встроенный веб-поиск openclaw через переменную окружения |
| `003-act-field-validation` | Исправляет логику валидации полей для browser act-действий |
| `005-browser-timeout-env-var` | Позволяет настраивать тайм-аут браузера (по умолчанию только 20 сек) |

## Быстрый старт

### 1. Подготовка API-ключей

Зарегистрируйтесь и получите ключи:
- [DeepSeek API](https://platform.deepseek.com/) — пополните счёт (для начала хватит ¥10 / ~$1.5)
- [SiliconFlow](https://cloud.siliconflow.cn/i/WNLYbBpi) (по реферальной ссылке — вы и проект получите по ¥16)

### 2. Установка

```bash
# Скачайте последний релиз с GitHub Releases и распакуйте
cd wiseflow
./scripts/install.sh
```

Скрипт `install.sh` автоматически:
- Клонирует openclaw и настраивает зависимости
- Инициализирует `openclaw.json` (с готовой конфигурацией моделей)
- Устанавливает системный daemon (автозапуск + перезапуск при сбоях)
- Интерактивно запрашивает API-ключи (только при первом запуске или если они отсутствуют)

**Режим отладки** (однократный запуск, подходит для тестирования):
```bash
./scripts/dev.sh gateway
```

**Системные требования**: рекомендуется Ubuntu 22.04; поддерживаются WSL2 и macOS; не рекомендуется запускать на Windows напрямую.

### 3. После установки

Подробная инструкция по использованию — в [docs/quick_start.md](docs/quick_start.md).
