# Social Graph Ranker

Движок взвешенного ранжирования социального графа для профессиональных связей.

Сценарии использования этого навыка:

- Ранжирование существующих общих профессиональных связей по ценности рекомендации
- Построение теплых путей к списку целей
- Оценка мостовой ценности однократных и двухкратных соединений
- Решение, какие цели подходят для теплых рекомендаций, а какие для прямого холодного взаимодействия
- Понимание алгоритма графа независимо от операционного процесса

## Когда использовать отдельно

Следующие требования выбирают этот навык:

- "Кто из моих профессиональных связей наиболее подходит для моей рекомендации?"
- "Ранжирование моих общих соединений по ценности рекомендации"
- "Сравнение моего графа профессиональных связей и цели клиента"
- "Показать логику расчета баллов моста"

Следующие требования **не должны** использовать этот навык отдельно:

- Необходим полный операционный процесс (исследование целей + черновик сообщения + очистка профессиональных связей) → Используйте `connections-optimizer`
- Необходимо отправить холодное письмо → Используйте `cold-outreach`

## Ввод

Соберите или выведите:

- Целевые лица, целевые компании или идеальный портрет клиента (ICP)
- Текущий граф профессиональных связей пользователя на LinkedIn / Maimai
- Приоритеты взвешивания (должность, отрасль, регион, активность ответа)
- Глубина обхода графа и толерантность к атenuации

## Ядерная модель

Определения:

- `T` = взвешенное множество целей
- `M` = прямые соединения / общие профессиональные связи пользователя
- `d(m, t)` = наименьшее количество прыжков от общего профессионального связи `m` к цели `t`
- `w(t)` = взвешивание цели (из оценки сигнала)

**Базовый балл моста:**

```text
B(m) = Σ_{t ∈ T} w(t) · λ^(d(m,t) - 1)
```

- `λ` — коэффициент атENUации, обычно `0.5`
- Прямой путь вносит максимальный вклад
- Каждый дополнительный прыжок вносит половину

**Расширение второго порядка:**

```text
B_ext(m) = B(m) + α · Σ_{m' ∈ N(m) \ M} Σ_{t ∈ T} w(t) · λ^(d(m',t))
```

- `N(m) \ M` — люди, которых знает общий профессиональный связь, но не знает пользователь
- `α` — дисконтный коэффициент второго порядка, обычно `0.3`

**Итоговое ранжирование с весом активности ответа:**

```text
R(m) = B_ext(m) · (1 + β · engagement(m))
```

- `engagement(m)` — нормализованная активность ответа или силу связей
- `β` — коэффициент усилений взаимодействия, обычно `0.2`

**Интерпретация уровня:**

- **Tier 1**: высокий `R(m)` + прямой путь моста → запрос теплой рекомендации
- **Tier 2**: средний `R(m)` + прямой путь моста → запрос рекомендации с условием
- **Tier 3**: низкий `R(m)` или отсутствие возможного пути → прямое холодное взаимодействие или заполнение пробела в профессиональных связях

## Сигналы оценки

Перед обходом графа взвесите цели в соответствии с текущим приоритетом бизнес-разработки:

- Соответствие должности / заголовку
- Согласованность компании / отрасли
- Последняя активность
- Географическая релевантность
- Влияние или охват
- Ожидаемая скорость ответа

После обхода графа взвесьте общие профессиональные связи:

- Количество взвешенных путей к целевому набору
- Прямолинейность путей
- Историческая активность ответа на взаимодействие
- Подходящий контекст для рекомендации этого человека

## Рабочий процесс

1. Построить взвешенное множество целей
2. Стянуть профессиональные связи пользователя с LinkedIn / Maimai
3. Вычислить базовые баллы моста
4. Для топовых общих профессиональных связей развернуть кандидатов второго порядка
5. Отранжировать по `R(m)`
6. Вывод:
   - Лучшие кандидаты для теплых рекомендаций
   - Условные пути моста
   - Пробелы без теплых путей (предлагаемые направления для заполнения)


## Связанные навыки

- `connections-optimizer` — внедрение этой модели ранжирования в полный операционный процесс (исследование целей + черновик сообщения + очистка профессиональных связей)
- `cold-outreach` — выполнение холодной электронной почты для целей без теплых путей
