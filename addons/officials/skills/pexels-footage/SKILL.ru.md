# Pexels Footage — Загрузка бесплатных изображений/видеоматериалов

Используйте этот навык, когда:
- Вам нужны реальные фотографии или видеоклипы (не сгенерированные ИИ) в качестве исходного материала
- Пользователь хочет профессионально выглядящий видеоматериал или изображения из Pexels
- Подготовка визуальных ресурсов для создания контента

**Предпосылки**: `PEXELS_API_KEY` должен быть установлен. Зарегистрируйтесь бесплатно на https://www.pexels.com/api/

---

## Использование

### Загрузка изображений

```bash
python3 {baseDir}/scripts/pexels_search.py \
  --type image \
  --terms "закат океан,горный пейзаж,лесная тропинка" \
  --aspect 16:9 \
  --output-dir ./assets/images \
  [--max-clips 15]
```

### Загрузка видео

```bash
python3 {baseDir}/scripts/pexels_search.py \
  --type video \
  --terms "закат океан,горный пейзаж,лесная тропинка" \
  --aspect 9:16 \
  --output-dir ./video_assets/footage \
  [--min-duration 5] \
  [--max-clips 15]
```

### Параметры

| Параметр | По умолчанию | Описание |
|--------|---------|-------------|
| `--terms` | required | Ключевые слова для поиска, разделенные запятыми (одно на сцену) |
| `--type` | `video` | `image` или `video` |
| `--aspect` | `9:16` | `9:16` (портрет) \| `16:9` (пейзаж) \| `1:1` (квадрат) |
| `--output-dir` | required | Директория для сохранения загруженных файлов |
| `--min-duration` | `5` | Минимальная продолжительность клипа в секундах (только для видео) |
| `--max-clips` | `15` | Максимум общих файлов для загрузки |

## Выход

### Выход изображения

```
✅ Загружено 12 изображений в ./assets/images/
   pexels-sunset-ocean-abc123.jpg  (1920x1280)
   pexels-mountain-def456.jpg      (2048x1365)
   ...
```

Возвращает JSON на stdout:
```json
{
  "ok": true,
  "images": ["path1.jpg", "path2.jpg"],
  "total": 12,
  "output_dir": "./assets/images"
}
```

### Выход видео

```json
{
  "ok": true,
  "clips": ["path1.mp4", "path2.mp4"],
  "total": 12,
  "output_dir": "./video_assets/footage"
}
```

## Обработка ошибок

| Ошибка | Действие |
|-------|--------|
| `PEXELS_API_KEY не установлен` | Проверьте переменные окружения |
| Результаты не найдены для термина | Попробуйте более широкие/простые ключевые слова (лучше всего работает на английском) |
| Загрузка не удалась | Повторите попытку; пропустите, если снова не удастся |
| Ограничение скорости (HTTP 429) | Подождите 60с, затем повторите |
