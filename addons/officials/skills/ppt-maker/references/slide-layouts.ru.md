# Справочник по макетам слайдов

Типы макетов слайдов и примеры конфигурации JSON, поддерживаемые ppt-maker.

## Общая структура конфигурации

```json
{
  "theme": {
    "primary_color": "1A1A2E",
    "secondary_color": "16213E",
    "accent_color": "E94560",
    "background_color": "FFFFFF",
    "text_color": "333333",
    "heading_font": "Microsoft YaHei",
    "body_font": "Microsoft YaHei"
  },
  "slides": [...]
}
```

## Типы слайдов

### 1. cover — Обложка

```json
{
  "type": "cover",
  "title": "Отчет о бизнесе за квартал",
  "subtitle": "Итоги и перспективы Q1 2026",
  "author": "Отдел бизнес-развития",
  "background_color": "1A1A2E",
  "background_image": "/path/to/ai_cover_bg.png"
}
```

- `background_image`: необязательно, фоновое изображение для обложки, сгенерированное ИИ (16:9, рекомендуется 1664x928)
- `background_color`: для чистого цветного фона или наложения маски на изображение

### 2. toc — Страница содержания

```json
{
  "type": "toc",
  "title": "Содержание",
  "items": ["Обзор рынка", "Ключевые достижения", "Проблемы и вызовы", "Планы на следующий квартал"]
}
```

### 3. content — Стандартная страница содержимого

Наиболее часто используемый тип слайда, поддерживает текст + необязательную иллюстрацию.

```json
{
  "type": "content",
  "title": "Обзор рынка",
  "body": "В Q1 2026 общий масштаб отрасли достиг...",
  "bullets": [
    "Рост доли рынка на 15%, превышает ожидания",
    "Добавлено 42 новых клиента, из них корпоративные клиенты составляют 60%",
    "Сохранение клиентов поддерживается на уровне 92%, выше среднего по отрасли"
  ],
  "image": "/path/to/chart.png",
  "image_position": "right"
}
```

- `image_position`: `"right"` (по умолчанию), `"left"`, `"bottom"`
- `body` и `bullets` могут использоваться одновременно, body перед, bullets после

### 4. two_column — Две колонки для сравнения

```json
{
  "type": "two_column",
  "title": "Анализ конкурентного сравнения",
  "left_title": "Мы",
  "left_body": ["ИИ-движок рекомендаций", "Автоматическая операция в режиме 7×24", "Гарантия безопасности данных"],
  "right_title": "Конкуренты",
  "right_body": ["Человек-правила-подход", "Операция в рабочее время", "Базовые меры безопасности"]
}
```

`left_body` / `right_body` поддерживают массив строк (по одной строке для каждого элемента списка) или чистый текст.

### 5. section — Разделительная страница

```json
{
  "type": "section",
  "number": "01",
  "title": "Обзор рынка",
  "subtitle": "Тренды отрасли, конкурентная среда и анализ возможностей",
  "background_color": "1A1A2E"
}
```

### 6. image_full — Страница с полной иллюстрацией

```json
{
  "type": "image_full",
  "title": "Демонстрация продукта",
  "caption": "Интерфейс основных функций",
  "image": "/path/to/screenshot.png"
}
```

### 7. ending — Благодарственная страница

```json
{
  "type": "ending",
  "title": "Спасибо за внимание",
  "subtitle": "Ожидание дополнительного обсуждения с вами",
  "contact": "Электронная почта: team@company.com | Телефон: 138-0000-0000",
  "qr_image": "/path/to/qrcode.png",
  "background_color": "1A1A2E"
}
```

## Стратегия иллюстраций

| Тип страницы | Рекомендации по иллюстрации | Рекомендуемый API |
|---------|---------|---------|
| Обложка | Абстрактный технологический/отраслевой фон, горизонтальный баннер 16:9 | siliconflow-img-gen (`--image-size 1664x928`) |
| Страницы содержимого | Концептуальная иллюстрация, графика данных, сценографическое изображение | siliconflow-img-gen + pexels-footage / pixabay-footage |
| Страницы с полной иллюстрацией | Высококачественный скриншот продукта /实景 фотография | Предоставляется пользователем |
| Благодарственная страница | Логотип бренда / QR-код | Предоставляется пользователем |

## Примечания по AI-иллюстрациям

1. Перед генерацией обложки/иллюстраций страниц включите название основного цвета (например, "глубокий синий") в текстовый запрос
2. Размер 16:9 для siliconflow-img-gen — `1664x928`
3. Обязательно проверьте, что сгенерированное изображение не является одноцветной белой доской (偶发异常 siliconflow)
4. Имена файлов изображений соответствуют индексу слайда (например, `slide_01_bg.png`)
