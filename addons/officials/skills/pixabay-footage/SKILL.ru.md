# Pixabay Footage — Альтернатива изображениям/видеоматериалам Pexels

Используйте этот навык, когда:
- Результаты Pexels не подходят или квота исчерпана
- Необходимы альтернативные изображения или видеоклипы без авторских прав
- Подготовка визуальных ресурсов для создания контента

**Предпосылки**: `PIXABAY_API_KEY` должен быть установлен. Зарегистрируйтесь бесплатно на https://pixabay.com/api/docs/

---

## Использование

### Загрузка изображений

```bash
python3 {baseDir}/scripts/pixabay_search.py \
  --type image \
  --terms "закат,океан,лес" \
  --aspect 16:9 \
  --output-dir ./assets/images \
  [--max-clips 15]
```

### Загрузка видео

```bash
python3 {baseDir}/scripts/pixabay_search.py \
  --type video \
  --terms "закат,океан,лес" \
  --aspect 9:16 \
  --output-dir ./video_assets/footage \
  [--min-duration 5] \
  [--max-clips 15]
```

Тот же интерфейс, что и `pexels-footage`. Формат вывода идентичен.

---

## Когда выбирать Pixabay против Pexels

| | Pexels | Pixabay |
|-|--------|---------|
| Качество фотографий | Высокое | Хорошее |
| Количество фотографий | 3M+ | 4M+ |
| Качество видео | Высокое (HD/4K) | Хорошее (HD) |
| Количество видео | 1M+ | 2M+ |
| Ограничения скорости | 200 запросов/час (бесплатно) | 100 запросов/мин (бесплатно) |
| Лучше для | Люди, природа, образ жизни | Объекты, абстракция, концепции |

Всегда используйте Pexels в первую очередь; переходите к Pixabay, если результаты недостаточны.

## Параметры

| Параметр | По умолчанию | Описание |
|--------|---------|-------------|
| `--terms` | required | Ключевые слова для поиска, разделенные запятыми (одно на сцену) |
| `--type` | `video` | `image` или `video` |
| `--aspect` | `9:16` | `9:16` (портрет) \| `16:9` (пейзаж) \| `1:1` (квадрат) |
| `--output-dir` | required | Директория для сохранения загруженных файлов |
| `--min-duration` | `5` | Минимальная продолжительность клипа в секундах (только для видео) |
| `--max-clips` | `15` | Максимум общих файлов для загрузки |

---

## Выход

Та же структура JSON, что и pexels-footage:
- `--type image` → `{"ok": true, "images": [...], "total": N, "output_dir": "..."}`
- `--type video` → `{"ok": true, "clips": [...], "total": N, "output_dir": "..."}`
