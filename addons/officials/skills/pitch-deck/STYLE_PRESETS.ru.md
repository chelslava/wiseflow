# Справочник по стилям

Визуальные стили для навыка `pitch-deck`.

Этот файл используется:
- Базовые CSS для обязательной адаптации по размеру окна просмотра
- Выбор стилей и отображение эмоций
- Примечания CSS и правила проверки

Используйте только абстрактные формы, если пользователь явно не требует иллюстрации.

## Адаптация по размеру окна просмотра — непреложный минимум

Каждый слайд должен полностью отображаться в одном окне просмотра.

### Золотое правило

```text
Каждый слайд =恰好 один высоты окна просмотра.
Слишком много контента = разделение на больше слайдов.
Внутри слайда никогда не следует прокручивать.
```

### Ограничения плотности

| Тип слайда | Максимальное количество контента |
|-----------|-----------|
| Обложка | 1 большой заголовок + 1 подзаголовок + необязательный слоган |
| Страницы содержимого | 1 заголовок + 4–6 пунктов или 2 коротких абзаца |
| Сетка функций | Максимум 6 карточек |
| Графика данных | 1 ключевой показатель или 1 изображение |
| Страница цитаты | 1 цитата + источник |
| Страница изображения | 1 изображение, высота не более 60vh |

## Чеклист по размеру окна просмотра

- Каждый `.slide` имеет `height: 100vh`, `height: 100dvh` и `overflow: hidden`
- Вся типографика использует `clamp()`
- Все интервалы используют `clamp()` или единицы окна просмотра
- Изображения имеют ограничение `max-height`
- Сетка использует `auto-fit` + `minmax()` для адаптивности
- Существуют три точки прерывания для низких экранов: `700px`, `600px`, `500px`
- При нехватке контента разделите слайды

## Каталог пресетов

- Атмосфера: Уверенность, высокая интенсивность, ощущение тематической речи

## Привязка чувств анимации

| Чувство | Направление анимации |
|------|---------|
| Драматичная / Кинематографичная | Медленное затухание, параллакс, крупное масштабирование |
| Технологичная / Будущая | Свечение, частицы, анимация сетки, кодировка текста |
| Жизнерадостная / Дружелюбная | Эластичное замедление, круги, плавающая анимация |
| Профессиональная / Корпоративная | Мини-анимации 200–300ms, чистый переключатель |
| Спокойная / Минималистичная | Предельно сдержанная анимация, приоритет пустого пространства |
| Редакционная / Журнальная | Сильное слоистое ощущение, текст и изображения поочередно появляются |

## Примечания CSS: Функции отрицания

**НЕ писать**:

```css
right: -clamp(28px, 3.5vw, 44px);
margin-left: -min(10vw, 100px);
```

Браузеры будут молча игнорировать эти записи.

**Обязательно заменить на**:

```css
right: calc(-1 * clamp(28px, 3.5vw, 44px));
margin-left: calc(-1 * min(10vw, 100px));
```

## Проверка размеров

По крайней мере протестируйте на следующих разрешениях:
- Десктоп: `1920x1080`, `1440x900`, `1280x720`
- Планшет: `1024x768`, `768x1024`
- Телефон: `375x667`, `414x896`
- Горизонтальный телефон: `667x375`, `896x414`

## Анимодели

Не использовать:
- Общий стартап-шаблон с градиентом фиолетового цвета и белым фоном
- Inter / Roboto / Arial как звуковой голос (если пользователь явно не хочет нейтральный практический стиль)
- Стена пуль (bullet wall), слишком маленький шрифт, бло-блоки, требующие прокрутки
- Использование декоративных иллюстраций, когда могут справиться абстрактные геометрические формы
