# Навык Pitch Deck

Генерация HTML презентаций с нулевыми зависимостями, богатыми анимациями для сценариев Business Developer/Investor Relationship, напрямую в браузере.

## Время активации

- Создание路演 PPT / финансовых выступлений для инвесторов
- Создание предложений о сотрудничестве / приглашений для партнерских союзах
- Создание демонстраций клиентам / презентаций продуктов
- Создание отчетов о случаях / квартальных обзоров
- Преобразование существующих файлов `.ppt` / `.pptx` в веб-презентации

## Обязательные требования

1. **Нулевые зависимости**: По умолчанию выводится один самодостаточный HTML файл (встроенные CSS + JS), может быть открыт в любом браузере.
2. **Принудительная адаптация по размеру окна просмотра**: Каждый слайд должен полностью отображаться в одном окне просмотра, запрещено внутреннее прокручивание.
3. **Визуальное первенство**: Использование визуального предпросмотра вместо абстрактных опросников стиля, пользователь выбирает ощущение, а не параметры.
4. **Бизнес-достоверность**: Избегайте дешевых градиентов, дизайна с шаблонным видом; презентация должна передавать профессионализм и доверие.
5. **Качество производства**: Код прокомментирован, поддерживает адаптивность, совместим с клавиатурой / сенсорным экраном / прокруткой мыши.

Перед генерацией обязательно прочитайте `STYLE_PRESETS.md`, чтобы получить базовые CSS для безопасного размера окна просмотра, ограничения плотности, предустановленные каталоги и примечания CSS.

## Рабочий процесс

### Шаг 1: Подтверждение режима

Выберите один из следующих путей:
- **Новая презентация**: У пользователя есть тема, пункты или полный черновик
- **Конверсия PPT**: У пользователя есть файл `.ppt` или `.pptx`
- **Оптимизация существующей**: У пользователя уже есть HTML презентация, требует улучшения

### Шаг 2: Понимание содержимого

Задайте только необходимые вопросы:

- **Назначение**:路演 / предложение о сотрудничестве / демонстрация клиентам / презентация продукта / отчет о случае
- **Целевая аудитория**: Инвесторы / потенциальные партнеры / клиенты / внутренняя команда
- **Количество страниц**: Короткая (5–10) / Средняя (10–20) / Длинная (20+)
- **Состояние содержимого**: Уже есть полный текст / Грубые пункты / Только тема

Если у пользователя есть содержимое, пусть он сначала вставит его, затем обсудите стиль.

### Шаг 3: Подтверждение типа и структуры презентации

В зависимости от назначения, предложите соответствующие рекомендации по стандартной структуре:

**路演 / Демонстрация для инвесторов (Investor Pitch)**
```
1. Обложка (название компании + описание в одном предложении)
2. Проблема (квантифицируйте болевые точки с данными)
3. Решение (что такое продукт/услуга)
4. Размер рынка (TAM / SAM / SOM)
5. Демонстрация продукта (скриншоты / основные функции)
6. Модель монетизации (как зарабатывать)
7. Сила (данные, клиенты, вехи)
8. Конкуренция (позиционирование для дифференциации)
9. Команда (ключевые участники + биографии)
10. Требования к финансированию (сумма + назначение + контактная информация)
```

**Предложение о сотрудничестве (Partnership Proposal)**
```
1. Обложка (название предложения + дата)
2. Фон (почему вам)
3. Кто мы (краткое описание компании + ключевые преимущества)
4. Способ сотрудничества (модель + процесс)
5. Взаимная выгода (что получит другая сторона)
6. Примеры (прошлые результаты партнерства)
7. Условия сотрудничества (обзор ключевых условий)
8. Следующие действия (CTA + контактная информация)
```

**Демонстрация клиентам / Презентация продукта**
```
1. Обложка (название продукта + ключевое торговое предложение)
2. Ваша болевая точка (описание сценария)
3. Наше решение (ключевые особенности функций)
4. Показ результатов (примеры / данные)
5. Цены (ясно и интуитивно понятно)
6. Частые вопросы (FAQ)
7. Начать использование (CTA + контактная информация)
```

### Шаг 4: Выбор стиля

По умолчанию запускается процесс визуального исследования.

Если пользователь знает нужный пресет, пропустите предпросмотр и используйте напрямую.

Иначе:
1. Уточните у пользователя, какое ощущение должна передавать презентация: **авторитетное и надежное / инновационное и энергичное / профессиональное и простое / элитное и изысканное**
2. Создайте **3 файла с предпросмотром на одной странице** в `.pitch-deck-previews/`
3. Каждый предпросмотр должен быть независимым, четко представлять макет/цвет/анимацию, контролируйте в пределах ~100 строк контента слайда
4. Спросите пользователя, какой保留, или смешать какие элементы

В зависимости от сценария, рекомендуется следующие пресеты (подробности в `STYLE_PRESETS.md`):

| Сценарий | Рекомендуемый пресет |
|---------|---------|
| pitch инвесторов | Bold Signal, Electric Studio |
| Предложение о сотрудничестве | Swiss Modern, Notebook Tabs |
| Премиум брендовые клиенты | Dark Botanical, Vintage Editorial |
| Технологический / ИИ продукт | Neon Cyber, Creative Voltage |
| Универсальный бизнес | Pastel Geometry, Split Pastel |

### Шаг 5: Построение презентации

Вывод файла:
- `pitch-deck.html`
- Или `[nome-do-tema]-pitch.html`

Создается папка `assets/` только при наличии внешних ресурсов изображения в презентации.

Обязательные структуры:
- Семантические слайды `<section>`
- Базовые CSS из `STYLE_PRESETS.md` для безопасного размера окна просмотра
- CSS кастомные свойства для управления переменными темы
- Класс контроллера демонстрации (навигация клавиатуры / колесика / сенсорного экрана)
- Intersection Observer для инициирования анимации при входе
- Поддержка `prefers-reduced-motion`

### Шаг 6: Принудительная адаптация по размеру окна просмотра

Считается обязательным критерием приемки.

Правила:
- Каждый `.slide` должен использовать `height: 100vh; height: 100dvh; overflow: hidden;`
- Все размеры шрифта и интервалы должны использовать `clamp()`
- При невозможности разместить контент, разбейте его на несколько слайдов
- Никогда не уменьшайте размер шрифта до неприемлемого уровня для решения переполнения
- Запрещено наличие полос прокрутки внутри слайда

Используйте ограничения плотности и обязательные CSS-блоки из `STYLE_PRESETS.md`.

### Шаг 7: Доставка

При доставке:
- Удалите временные файлы предпросмотра (если пользователь не требует их сохранения)
- Откройте файл с помощью подходящего для текущей системы способа:
  - macOS: `open file.html`
  - Linux: `xdg-open file.html`
  - Windows: `start "" file.html`
- Сведите: путь к файлу, используемый пресет, количество слайдов, методы настройки темы

## Конверсия PPT / PPTX

```bash
python3 {baseDir}/scripts/extract_pptx.py <file.pptx> [--images-dir /tmp/pptx_images]
```

Скрипт выводит JSON, содержащий заголовок, тело, заметки спикера и пути к изображениям (если указан `--images-dir`) для каждого слайда.

- Если `python-pptx` не установлен (вывод `error` поле), спросите пользователя, установить ли ( `pip install python-pptx`), или понизьте до ручного потоковую вставку
- После извлечения пройдите через тот же процесс выбора стиля, что и новая презентация, сохраняя порядок слайдов, заметки спикера и ресурсы изображений

Обеспечьте кросс-платформенную совместимость, не полагаясь на macOS-специфичные инструменты.

## Требования реализации

### HTML / CSS

- Используйте встроенные CSS и JS (если пользователь явно не требует многофайлового проекта)
- Шрифты могут быть из Google Fonts или Fontshare
- Предпочтительно используйте абстрактные формы, градиенты, сетки, геометрические фигуры, а не иллюстрации
- Бизнес-презентации должны передавать ощущение профессионализма и доверия;路演 должен передавать уверенность и амбиции

### JavaScript

Обязательные:
- Навигация клавиатурой (← → стрелки / Space)
- Навигация.touch / swipe
- Навигация колесиком мыши
- Индикатор прогресса или индекс слайдов
- Инициатор анимации при входе (Intersection Observer)

### Доступность

- Используйте семантическую структуру ( `main`, `section`, `nav`)
- Поддерживайте достаточный контраст цветов
- Поддерживайте чистую навигацию клавиатурой
- Соблюдайте `prefers-reduced-motion`

## Ограничения плотности содержимого

| Тип слайда | Максимум |
|-----------|------|
| Обложка | 1 большой заголовок + 1 подзаголовок + необязательный слоган |
| Страницы содержимого | 1 заголовок + 4–6 пунктов или 2 коротких абзаца |
| Сетка функций | Максимум 6 карточек |
| Графика данных | 1 ключевой показатель или 1 изображение |
| Цитата / Поддержка клиента | 1 цитата + источник |
| Страницы изображений | 1 изображение, высота не более 60% окна просмотра |

## Анимодели

- Дешевый градиент фиолетового цвета + общий шаблон интерпретации
- Стена пуль (bullet wall)
- Блоки кода, требующие прокрутки для просмотра
- Уменьшение размера шрифта вместо разделения слайдов при высокой плотности контента
- Недействительные CSS функции отрицания, такие как `-clamp(...)` или `-min(...)`

## Чеклист доставки

- [ ] Презентация может быть запущена напрямую в браузере из локального файла
- [ ] Каждый слайд полностью отображается в окне просмотра без прокрутки
- [ ] Стиль соответствует целевой аудитории и сценарию
- [ ] Анимация имеет значение, не отвлекает
- [ ] Поддержка reduced-motion
- [ ] При доставке укажите путь к файлу, выбор пресета, количество слайдов и методы настройки
