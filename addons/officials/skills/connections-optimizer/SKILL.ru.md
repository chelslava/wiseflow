# Навык Connections Optimizer

Используйте этот навык, когда:
- Необходимо взаимодействовать с конкретным целевым лицом/компанией, но нет прямых знакомых
- Хотите знать "Кто может мне порекомендовать XX"
- Необходимо подготовить черновик первого сообщения взаимодействия (LinkedIn / Maimai / электронная почта) для конкретной цели
- Хотите очистить подписки/связи, не соответствующие текущему направлению бизнеса
- Необходимо обнаружить новых целевых лиц в конкретном круге (отрасль, город, функция)

---

## Шаг 1 — Уточнение целей и приоритетов

Задайте пользователю (если еще не предоставлено):

```
1. Кто является целью? (Название компании / Имя человека / Должность + Отрасль + Регион)
2. Какова цель? (Поиск сотрудничества / Привлечение клиентов / Взаимодействие с инвесторами / Расширение ресурсов экосистемы)
3. Платформа для операции? (LinkedIn / Maimai / X, может быть несколько, по умолчанию LinkedIn + Maimai)
4. Тип задачи:
   A. Поиск теплых путей + Подготовка черновика сообщения первого взаимодействия (по умолчанию)
   B. Очистка низкоценных подписок
   C. Обнаружение новых целевых лиц
   D. Полная (A + B + C)
```

При отсутствии указанного типа задачи по умолчанию выполняется A.

---

## Шаг 2 — Исследование целевых лиц

Для каждого целевого лица последовательно выполните через browser:

```
LinkedIn:
1. Открыть https://www.linkedin.com/search/results/people/
   Ключевые слова поиска: "{имя}" OR "{должность} @ {компания}"
2. Перейти на наиболее подходящую страницу Profile
3. Извлечь:
   - Имя, текущая должность, компания
   - Местоположение
   - Образование (учебное заведение + год окончания)
   - Последние публикации (посты/пересылки, последние 3)
   - Количество общих связей (отображается на странице)
   - Теги навыков/поддержек (первые 5)

Maimai (если выбран):
1. Открыть https://maimai.cn/search/user?query={имя}
2. Перейти на наиболее подходящую страницу Profile
3. Извлечь:
   - Имя, текущая должность, компания
   - Количество общих знакомых (отображается на странице)
   - Тег校友 (одно и то же учебное заведение)
   - Тег бывших коллег (были ли共事过)

При появлении стены входа → Пропустить платформу, продолжить другие каналы
При появлении CAPTCHA → Остановиться, сообщить пользователю
```

Одновременно используйте веб-поиск для дополнения открытой информации:

```
Поиск: "{имя} {компания}" site:linkedin.com OR site:twitter.com
Поиск: "{название компании}" финансирование OR сотрудничество OR новости последние 3 месяца

Извлечь:
- Последние новости компании (финансирование, новый продукт, объявления о сотрудничестве)
- Публичные высказывания или статьи целевого лица
- Участие в последних отраслевых конференциях
```

## Шаг 3 — Распознавание теплых путей

```
Для каждой цели отсортируйте теплые пути по следующему приоритету:

Приоритет 1 — Прямые общие связи (самые сильные)
  LinkedIn: Нажмите "общие связи" на Profile, чтобы увидеть конкретные имена
  Maimai: Просмотр списка "общих знакомых"
  → Запись: Имя посредника, связь между посредником и BD, связь между посредником и целью

Приоритет 2 — Косвенные пути (2 степени)
  Из общих связей ищите, есть ли кто-то с той же компанией/учебным заведением/бывшими коллегами

Приоритет 3 — Мягкие связи
  - Одно и то же отраслевое ассоциация/организация
  - Студенты одно и то же поколения (круг校友 Maimai)
  - Участие в одной и той же конференции (вывод из публичной информации)
  - Перекрытие бывших работодателей

Приоритет 4 — Отсутствие теплых путей
  → Пометить как холодное взаимодействие, рекомендовать LinkedIn InMail или прямую отправку электронной почты
```

## Шаг 4 — Идентификация окна时机

```
Проверьте следующие сигналы для оценки时机 для взаимодействия:

Благоприятное时机 для взаимодействия (плюс):
  ✓ announced финансирование компании в последние 30 дней
  ✓ Целевое лицо изменило должность в последние 30 дней
  ✓ Компания недавно выпустила новый продукт/услугу
  ✓ Целевое лицо публикует в социальных сетях о темах, связанных с бизнесом BD
  ✓ Предстоящая отраслевая конференция, цель, возможно, будет присутствовать

Неблагоприятное时机 для взаимодействия (минус):
  ✗ Недавно негативные новости о компании компании (сокращения, судебные иски, неудачное финансирование)
  ✗ Целевое лицо не имеет никакой публичной активности в течение длительного времени (безмолвствие>3 месяцев)
  ✗ BD уже взаимодействовал недавно, но не получил ответа (<30 дней)
```

## Шаг 5 — Создание черновика сообщения первого взаимодействия

Выберите шаблон сообщения на основе типа теплого пути, сгенерируйте персонализированное содержимое LLM:

### Есть общие связи (через посредника)

```
Канал: Вичат или электронная почта для посредника

LLM Prompt:
"Помогите мне составить сообщение для {имя посредника}, запрашивающее рекомендацию {имя цели} ({должность цели} @ {компания цели}).

Контекст:
- Я ({имя}) хочу {цель, например: обсудить сотрудничество / понять направление их продуктов}
- Отношения между мной и посредником: {например: бывшие коллеги / однокурсники / несколько раз встречались на конференциях}
- Отношения {имя цели} и посредника (если известно): {отношения}
- Последние события компании {цель} (если есть)

Требования:
- Китайский язык, разговорный, не более 100 слов
- Четко объясните причину запроса рекомендации без обходных маршрутов
- Предоставьте посреднику простой выход для отказа
- Без маркетингового的味道
- Один абзац в конце для завершения, без формального приветствия

Возвращайте только текст сообщения, без каких-либо объяснений."
```

### Нет общих связей — LinkedIn InMail / Запрос на соединение

```
LLM Prompt:
"Помогите мне составить сообщение запроса на соединение LinkedIn для {имя цели} ({должность цели} @ {компания цели}).

Контекст:
- Я {имя}, {моя личность/компания/одно предложение о моем основном бизнесе}
- Цель взаимодействия: {например, обсудить возможность сотрудничества в области услуг данных}
- Причина, по которой я нашел это лицо: {например, увидел, что они недавно выпустили продукт XX}
- Соответствующий时机: {например, ваша компания недавно завершила раунд B, расширяя команду}

Требования:
- Английский (международный контекст LinkedIn) или китайский (китайский рабочий контекст), указанный пользователем, по умолчанию английский
- Не более 300 символов (ограничение запроса на соединение LinkedIn)
- Первое предложение должно быть персонализированным, не "Я хотел бы добавить вас в мою сеть"
- Не продвигайте в первое сообщение, сосредоточьтесь на установлении связи
- Завершите низким трением CTA (15-минутный разговор / ответ на электронную почту)

Возвращайте только текст сообщения."
```

### Нет общих связей — Приватное сообщение Maimai

```
LLM Prompt:
"Помогите мне составить приватное сообщение Maimai для {имя цели} ({должность цели} @ {компания цели}).

Контекст:
- Я {имя}, {одно предложение о себе}
- Цель взаимодействия: {цель}
- Причина поиска этого человека: {причина}

Требования:
- Китайский язык, разговорный
- Не более 100 слов
- В первом предложении дайте对方 причину для ответа мне
- В конце четкий вопрос или предложение (не двусмысленное "поговорим, когда будет время")
- Без чувства массовой рассылки

Возвращайте только текст сообщения."
```

### Холодная электронная почта

```
LLM Prompt:
"Помогите мне составить холодную электронную почту для {имя цели} ({должность цели} @ {компания цели}).

Контекст:
- Отправитель: {имя}, {должность}, {компания}, {одно предложение о компании}
- Цель: {цель}
- Почему именно он/она: {например, увидел, что ваша компания сейчас...}
- Последний时机: {если есть: ваша компания недавно получила финансирование/выпустила новый продукт/участвовала в XX конференции}

Требования:
- Китайский язык
- Subject line: персонализированная, не более 15 слов, без восклицательных знаков
-正文: 3 абзаца, всего не более 150 слов
  Первый абзац: почему письмо (персонализированное введение, основанное на последних событиях)
  Второй абзац: какую ценность мы можем предложить (с точки зрения对方, а не о себе)
  Третий абзац: CTA, конкретный запрос с низким трением
- В конце не чрезмерное вежливое завершение

Формат возвращения:
Subject: [Subject line]
---
[正文 электронной почты]"
```

## Шаг 6 — Очистка низкоценных подписок (только для типов задач B / D)

```
LinkedIn:
1. Открыть https://www.linkedin.com/mynetwork/import-contacts/
2. Условия фильтрации (выполнять по порядку):
   a. Перечислить 1-степени связей без взаимодействия за последние 90 дней
   b. Для каждой связи проверить: имеет ли она отношение к текущему направлению BD (отрасль/должность/компания)
   c. Пометить как "кандидат в очистку": без взаимодействия + несоответствие
   d. Создать очередь очистки с указанием причин

Maimai:
1. Открыть https://maimai.cn/contact
2. Той же логике, уделяя внимание:
   - Односторонние подписки (пользователь не подписан обратно) + отсутствие взаимодействия > 6 месяцев
   - Отрасль/должность полностью не соответствуют направлению

Примечание:
- Создать очередь очистки, не выполнять автоматически
- Все операции требуют подтверждения пользователя
- Со связями, с которыми уже установлены деловые отношения, даже без взаимодействия, не включать в очередь очистки
```

После сбора всей информации выведите следующий формат для подтверждения:

```
━━ ОТЧЕТ OPTIMIZER КОННЕКЦИЙ ━━

Анализ целевого лица
─────────────
[имя цели] | [должность] @ [компания] | [платформа]

Резюме исследования:
  · Последние события: [самые релевантные 1-2]
  · Время для взаимодействия: [хорошо / среднее / плохо] — Причина: [одно предложение]

Теплые пути:
  · [имя посредника] ([отношения с BD]) → знакомы с [имя цели] ([тип отношений])
  · Отсутствие теплых путей (рекомендовано холодное взаимодействие)

Рекомендуемый канал: [LinkedIn InMail / Рекомендация через X / Приватное сообщение Maimai / Электронная почта]

Черновик сообщения:
  [вставить соответствующий черновик канала]

─────────────

[список: Имя | Платформа | Причина очистки | Уровень достоверности]

━━ Рекомендации новых целей (если выполнялась задача C/D) ━━━
[список: Имя/Компания | Причина | Рекомендуемый канал]

━━ Следующие действия ━━
□ Подтвердить отправку вышеуказанных черновиков сообщений
□ Подтвердить очередь очистки для выполнения
□ Требуется изменение стиля черновика? Укажите
```

## Обработка ошибок

| Ситуация | Способ обработки |
|------|---------|
| LinkedIn показывает стену входа | Пропустить платформу, использовать Maimai/X/веб-поиск, сообщить пользователю |
| Maimai CAPTCHA | Остановиться, сообщить пользователю о необходимости ручного завершения шага |
| Профиль цели не найден | Сообщить пользователю, предложить предоставить больше информации (полное имя/компания/регион) |
| Отсутствие теплых путей | Пометить холодное взаимодействие, сгенерировать черновик LinkedIn InMail или электронной почты |
| Недавние негативные новости о компании цели | Значительно отметить в пакете обзора, рекомендовать отложить взаимодействие |

---

## Примечания

- Операции очистки требуют явного подтверждения пользователя, **не автоматически удалять**
- При наличии примеров сообщений пользователя, приоритетно использовать реальный стиль его речи
