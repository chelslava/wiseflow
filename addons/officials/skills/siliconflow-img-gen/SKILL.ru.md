# Генерация изображений SiliconFlow

Генерация или редактирование изображений с использованием API SiliconFlow Images.

Два режима:
- **Текст-в-изображение** — модель по умолчанию `Qwen/Qwen-Image` (если превышен лимит скорости, возвращается к `baidu/ERNIE-Image-Turbo`)
- **Редактирование изображения** — модель по умолчанию `Qwen/Qwen-Image-Edit-2509`, инициируется параметром `--image`

## Запуск

Примечание: Генерация изображения может занять 10–60 секунд. Установите более высокий тайм-аут при вызове через exec (например, `exec timeout=120`).

**НЕ устанавливайте переменные окружения в строке** (например, `SILICONFLOW_API_KEY=... python3 ...`). Переменная окружения уже в системной среде; встроенные присваивания нарушают проверку разрешений exec.

```bash
# Текст-в-изображение (модель по умолчанию: Qwen/Qwen-Image)
python3 {baseDir}/scripts/gen.py --prompt "ваш текстовый запрос здесь"

# если превышен лимит скорости, возвращается к `baidu/ERNIE-Image-Turbo`
python3 {baseDir}/scripts/gen.py --prompt "ваш текстовый запрос здесь" --model "baidu/ERNIE-Image-Turbo"

# Редактирование изображения (модель по умолчанию: Qwen/Qwen-Image-Edit-2509)
python3 {baseDir}/scripts/gen.py --prompt "добавить маяк" --image "https://example.com/source.jpg"
```

### Примеры текст-в-изображения

```bash
# Квадратный результат (по умолчанию)
python3 {baseDir}/scripts/gen.py --prompt " футуристический город на закате"

# Пейзаж 16:9
python3 {baseDir}/scripts/gen.py --prompt "горное озеро" --image-size 1664x928

# Портрет 9:16
python3 {baseDir}/scripts/gen.py --prompt "горное озеро" --image-size 928x1664

# Включить CFG (полезно, когда текстовый запрос содержит текст для визуализации)
python3 {baseDir}/scripts/gen.py --prompt "знак, говорящий HELLO" --cfg 4.0 --steps 50

# Сохранить в определенную директорию
python3 {baseDir}/scripts/gen.py --prompt "закат" --out-dir ./out/images
```

### Примеры редактирования изображения

```bash
# Редактирование с одним исходным изображением
python3 {baseDir}/scripts/gen.py \
  --prompt "сделать его ночью" \
  --image "https://example.com/photo.jpg"

# Редактирование с помощью до трех исходных изображений
python3 {baseDir}/scripts/gen.py \
  --prompt "смешать эти фотографии" \
  --image  "https://example.com/a.jpg" \
  --image2 "https://example.com/b.jpg" \
  --image3 "https://example.com/c.jpg"
```

## Параметры

| Флаг | По умолчанию | Описание |
|------|---------|-------------|
| `--prompt` | required | Текстовое описание изображения |
| `--model` | auto | ID модели; автоматически выбирается режимом, если опущено |
| `--image-size` | `1328x1328` | Разрешение (только для текст-в-изображения, см. допустимые значения ниже) |
| `--steps` | `20` | Шаги вывода (1–100) |
| `--cfg` | — | Масштаб CFG (0.1–20). Qwen рекомендует 4.0 при генерации текста в изображении; должно быть >1 для генерации текста |
| `--seed` | — | Случайное семя (0–9999999999) |
| `--image` | — | URL исходного изображения — **включает режим редактирования изображения** |
| `--image2` | — | URL второго исходного изображения (только режим редактирования) |
| `--image3` | — | URL третьего исходного изображения (только режим редактирования) |
| `--out-dir` | `./tmp/sf-img-<ts>` | Выходная директория |

### Допустимые значения `--image-size` (Qwen/Qwen-Image)

| Значение | Соотношение |
|-------|-------|
| `1328x1328` | 1:1 (по умолчанию) |
| `1664x928` | 16:9 |
| `928x1664` | 9:16 |
| `1472x1140` | 4:3 |
| `1140x1472` | 3:4 |
| `1584x1056` | 3:2 |
| `1056x1584` | 2:3 |

## Выход

- Изображения `*.png`, названные по индексу
- `prompts.json` сопоставление индекса → текстовый запрос + URL
- `index.html` галерея миниатюр

## ⚠️ Обязательная проверка после генерации

Генерация изображений SiliconFlow часто встречает аномалии: возвращает **одноцветную фоновую картинку** (одноцветный без содержания), вместо изображения, требуемого текстовым запросом.

**Обязательно выполнить проверку для каждого сгенерированного изображения, не пропускать.**

### Процесс проверки

1. После генерации изображения немедленно просмотреть сгенерированное изображение с помощью инструмента `image`
2. Определить, нормально ли изображение:
   - ❌ **Аномалия**: вся картинка одноцветного фона (全黑/全白/全灰/全蓝 и т.д.), без какого-либо основного содержания → **сгенерировать повторно**
   - ✅ **Нормально**: изображение имеет четкое основное содержание, соответствует описанию текстового запроса → продолжить на следующий шаг
3. Если повторная генерация, попробовать не более 3 раз, при аномалии пометить как неудачу и продолжить последующие задачи
