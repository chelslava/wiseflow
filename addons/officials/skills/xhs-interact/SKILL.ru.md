# Социальное взаимодействие Xiaohongshu

Выполняет социальное взаимодействие на Xiaohongshu (xhs) для пользователя через **browser tool**.

**Предпосылки**: Необходимо сначала войти в Xiaohongshu через browser tool (следуя процедуре входа QR в разделе 6 browser-guide), browser уже имеет действительную сессию.

---

## Получение feed_id и xsec_token

Все операции взаимодействия требуют `feed_id` и `xsec_token`, полученные из адресной строки браузера:

```
Формат URL заметки:
https://www.xiaohongshu.com/explore/{feed_id}?xsec_token={xsec_token}&xsec_source=pc_feed

Пример:
https://www.xiaohongshu.com/explore/64abc123def456?xsec_token=ABxxxxxx&xsec_source=pc_feed
→ feed_id    = 64abc123def456
→ xsec_token = ABxxxxxx
```

---

## Обязательные ограничения

- Выдерживайте интервал 30-60 секунд между операциями при массовом выполнении, чтобы избежать риска контроля качества.
- Не более 20 комментариев в день.

---

## Формат URL страницы сведений о фиде

```
https://www.xiaohongshu.com/explore/{feed_id}?xsec_token={xsec_token}&xsec_source=pc_feed
```

## Рабочий процесс

### Публикация комментария

```
1. Перейдите на страницу сведений о фиде (используя вышеуказанный формат URL)
2. Дождитесь загрузки страницы, проверьте, accessible ли страница
   (появление .access-wrapper / .error-wrapper означает, что заметка недоступна, остановитесь и сообщите пользователю)
3. Введите содержимое комментария в элемент .content-input
4. Триггер input событие
5. Нажмите кнопку отправки
6. Подождите 1-2 секунды, чтобы подтвердить, что комментарий появился в разделе комментариев
```

### Ответ на комментарий

```
1. Перейдите на страницу сведений о фиде
2. Дождитесь загрузки страницы (2-3 секунды), подтвердите, что страница accessible
3. Прокрутите к целевому комментарию:
   - Известный comment_id: найдите элемент #comment-{comment_id} и прокрутите до видимости
   - Известный user_id: найдите элемент комментария, содержащий data-user-id="{user_id}", и прокрутите до видимости
   - Если требуется прокрутка для загрузки дополнительных комментариев: прокрутите вниз по частям (остановитесь после 7 прокруток),
     подождите 0.5-1 секунду после каждой прокрутки для наблюдения загрузки комментариев, достижение .end-container означает достижение дна
4. Нажмите кнопку ответа на целевой комментарий (селектор: .interactions .reply)
5. Введите содержимое ответа в элемент .content-input
6. Триггер input событие
7. Нажмите кнопку отправки
8. Подождите 1-2 секунды, чтобы подтвердить отправку ответа
```

### Лайк / Отмена лайка

**Селектор**: `.like-wrapper` (рекомендуется) или `.interact-container .left .like-wrapper`

```
1. Перейдите на страницу сведений о фиде
2. Дождитесь полной загрузки страницы (2-3 секунды)
3. Проверьте текущий статус лайка через snapshot страницы или JavaScript
    - Лайк установлен: элемент .like-wrapper содержит класс like-active
4. Нажмите кнопку лайка:
    - Способ A (CDP click): browser act kind=click ref=xxx
    - Способ B (JavaScript evaluate, рекомендуется): document.querySelector('.like-wrapper').click()
5. Подождите 1-2 секунды, чтобы подтвердить изменение статуса
6. Если статус не изменился, повторите еще раз
```

**Подсказка CDP режима**: Если CDP click истекает, используйте метод JavaScript evaluate:
```javascript
// Нажмите кнопку лайка
document.querySelector('.like-wrapper').click();

// Проверьте статус лайка
document.querySelector('.like-wrapper').classList.contains('like-active') ? 'Лайк установлен' : 'Лайк не установлен';
```

## Обработка ошибок

| Ситуация | Обработка |
|------|------|
| На странице появляется стена входа | Следуйте процедуре входа QR в разделе 6 browser-guide, отсканируйте и повторите |
| Статус лайка не изменился | Повторите еще раз, если изменения не произошло, сообщите об ошибке |
| CDP click истек | Используйте метод JavaScript evaluate: browser act kind=evaluate fn="document.querySelector('.like-wrapper').click()" |
