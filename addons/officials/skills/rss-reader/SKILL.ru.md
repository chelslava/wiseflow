# RSS / Atom Feed Reader

Используйте этот навык, когда:
- Пользователь хочет отслеживать или извлекать обновления с веб-сайта
- Пользователь напрямую предоставляет URL RSS или Atom feed
- Вам необходимо эффективно собрать несколько статей из одного источника без посещения каждой страницы

---

## Шаг 1 — Обнаружение URL feed

Если у вас уже есть RSS/Atom URL, перейдите к Шагу 2.

**Метод A — исходный код страницы**
Перейдите на веб-сайт, сделайте снимок и ищите теги `<link rel="alternate">` в `<head>`:
```html
<link rel="alternate" type="application/rss+xml" href="/feed">
<link rel="alternate" type="application/atom+xml" href="/atom.xml">
```

**Метод B — распространенные пути** (пробуйте один за другим, пока один не вернет XML)
```
/feed  /feed.xml  /rss  /rss.xml  /atom.xml  /index.xml
/?feed=rss2  /feeds/posts/default
```

**Метод C** — ищите RSS иконки 🟠 или ссылки, помеченные как "RSS", "Subscribe", "Feed".

Действительный URL feed возвращает XML, начинающийся с `<rss`, `<feed` или `<rdf:RDF`.

---

## Шаг 2 — Запуск скрипта

```bash
node /path/to/wiseflow/skills/rss-reader/scripts/fetch-rss.mjs <feed_url> [--limit N] [--skip url1,url2,...]
```

| Опция | Описание |
|--------|-------------|
| `--limit N` | Максимум возвращаемых записей (по умолчанию: 20) |
| `--skip url1,url2,...` | Пропустить записи, чьи URL уже обработаны (дедупликация) |

**Выход** — markdown с двумя разделами:
1. **Полностью содержимые статьи** — записи, которые включают полное тело статьи (>200 символов). Обрабатывайте эти напрямую; **не требуется посещение URL статьи**.
2. **Ссылки только с резюме** — записи с только коротким отрывком. Посетите каждый URL для получения полного содержимого.

---

## Шаг 3 — Обработка результатов

- Для статей с полным содержимым: извлеките заголовок, автора, дату и содержимое напрямую из вывода скрипта.
- Для ссылок только с резюме: используйте `browser.navigate(url)` для получения каждой страницы статьи.
- Передайте вывод скрипта напрямую пользователю или в ваш processing pipeline.

---

## Пограничные случаи

| Ситуация | Действие |
|-----------|--------|
| Feed возвращает 404 | Попробуйте альтернативные пути из Шага 1 |
| Feed требует входа | Следуйте навыку **browser-guide** |
| Ошибка скрипта "Failed to parse feed" | XML feed может быть поврежден; сообщите URL пользователю |
| Пустой feed | Сообщите: "Этот RSS feed не содержит записей." |
