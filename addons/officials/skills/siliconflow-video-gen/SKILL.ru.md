# Генерация видео SiliconFlow

Генерация видео с использованием API SiliconFlow Video (модели Wan2.2).

Генерация видео **асинхронна**: API возвращает `requestId` немедленно, затем скрипт опрашивает конечную точку статуса до завершения задания (статус: `Succeed`).

> Ссылка на сгенерированное видео действительна в течение **1 часа**. Скрипт автоматически загружает видео локально.

## Запуск

Примечание: Генерация видео обычно занимает **1–5 минут**. Установите соответствующее время выполнения тайм-аута (например, `exec timeout=600`).

```bash
# Текст-в-видео
python3 {baseDir}/scripts/gen.py --prompt "дельфин, перескакивающий через океанские волны на закате"

# Изображение-в-видео (предоставьте публичную URL или локальное base64 изображение)
python3 {baseDir}/scripts/gen.py \
  --model "Wan-AI/Wan2.2-I2V-A14B" \
  --prompt "камера медленно отдаляется" \
  --image "https://example.com/my-photo.jpg"

# Пользовательское разрешение и выходная директория
python3 {baseDir}/scripts/gen.py \
  --prompt "тайм-капсула цветущего цветка" \
  --image-size 720x1280 \
  --out-dir ./out/videos

# Воспроизводимая генерация с фиксированным семенем
python3 {baseDir}/scripts/gen.py --prompt "запуск ракеты" --seed 42
```

## Параметры

| Флаг | По умолчанию | Описание |
|------|---------|-------------|
| `--prompt` | required | Текстовое описание видео |
| `--model` | `Wan-AI/Wan2.2-T2V-A14B` | ID модели: `Wan-AI/Wan2.2-T2V-A14B` (T2V) или `Wan-AI/Wan2.2-I2V-A14B` (I2V) |
| `--image` | — | URL изображения или `data:image/...;base64,...` (обязательно для модели I2V) |
| `--image-size` | `1280x720` | Разрешение: `1280x720` (16:9), `720x1280` (9:16), `960x960` (1:1) |
| `--negative-prompt` | — | Что избегать в видео |
| `--seed` | — | Семя для воспроизводимости |
| `--poll-interval` | `10` | Секунды между опросами статуса |
| `--timeout` | `600` | Максимум секунд ожидания генерации |
| `--out-dir` | `./tmp/sf-video-<ts>` | Выходная директория |

## Модели

| Модель | Тип | Примечания |
|-------|------|-------|
| `Wan-AI/Wan2.2-T2V-A14B` | Текст → Видео | Модель по умолчанию |
| `Wan-AI/Wan2.2-I2V-A14B` | Изображение → Видео | Требует параметра `--image` |

## Выход

- `video_<requestId>.mp4` загружается локально
- `result.json` с полным ответом API

| `SILICONFLOW_API_KEY` | Ваш API-ключ SiliconFlow (обязательно) |
