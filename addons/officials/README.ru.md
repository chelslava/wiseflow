# Официальный адлон wiseflow

Официальный аддон, поставляемый с версией wiseflow с открытым исходным кодом, предоставляет дополнительные глобальные навыки и шаблоны Крейсов поверх глобальных навыков `skills/` и базовых патчей `patches/` в wiseflow.

## 1. Дополнительные глобальные навыки (skills/)

После установки видны всем крейсам (ограничены DENIED_SKILLS / DECLARED_SKILLS):

| Навык | Функция | Требуемые переменные окружения | Область применения |
|------|------|------------|----------|
| `rss-reader` | Чтение RSS/Atom Feed, поддержка подписки на любые источники контента в стандартном формате feed | — | Доступно всем крейсам |
| `siliconflow-img-gen` | Генерация изображений, редактирование изображений (API SiliconFlow) | `SILICONFLOW_API_KEY` | designer, selfmedia-operator |
| `siliconflow-video-gen` | Генерация видео / изображение в видео (API SiliconFlow) | `SILICONFLOW_API_KEY` | selfmedia-operator |
| `connections-optimizer` | Оптимизация и расширение сети профессиональных связей | — | **Только business-developer**; остальные крейсы DENIED |
| `email-ops` | Массовое создание сообщений электронной почты и отправка через SMTP | `SMTP_SERVER` `SMTP_USER` `SMTP_PASSWORD` | **Только business-developer**; остальные крейсы DENIED |
| `pitch-deck` | Генерация презентаций для привлечения инвестиций / бизнес-презентаций, поддержка чтения содержимого файлов .pptx | — | **Только business-developer**; остальные крейсы DENIED |
| `social-graph-ranker` | Анализ и ранжирование ключевых узлов социального графа | — | **Только business-developer**; остальные крейсы DENIED |

## 2. Шаблоны Крейсов (crew/)

Готовые к производству шаблоны Крейсов, предоставляемые официально, которые могут быть инстанцированы одной командой `setup-crew.sh`:

| Crew / Слой навыков | Основные возможности |
|---|---|
| **selfmedia-operator** | Регистрация вдохновения в повседневной жизни, сбор материалов; исследование тем → визуальный и текстовый контент, черновик-расширение → полная статья; генерация коротких видео с помощью ИИ; поддержка публикации на juejin / Medium / zhihu / toutiao / Twitter / Instagram / TikTok / YouTube; способен автономно вызывать designer для иллюстраций |
| **business-developer** | Оптимизация и расширение сети профессиональных связей; массовое создание и отправка сообщений электронной почты; генерация презентаций для привлечения инвестиций / бизнес-презентаций; анализ и ранжирование ключевых узлов социального графа |
| **sales-cs** | Первая встреча, предпродажная консультация, интеграция продажного руководства; автоматическое обслуживание базы данных клиентов ( состояние операций, каналы источников, отслеживание потенциальных клиентов); встроенные навыки инициации платежа, приглашения на опыт, автоматическое последующее следование в случае, если клиент говорит, что связаться позже; интеллектуальное определение перехода на человеческое обслуживание |
| **designer** | Генерация изображений, редактирование изображений; может быть вызван другими крейсами через `sessions_spawn` |

---

#### sales-cs — Клиент службы продаж

**Тип**: Внешний (`T0` разрешения)

С фокусом на **заключении сделки** в качестве основной цели, а не просто пассивном ответе на вопросы.

- Первая встреча, предпродажная консультация, интеграция продажного руководства
- Принципы речи: сначала принимаем → затем оцениваем → даем вывод → предлагаем следующий шаг
- Автоматическое обслуживание базы данных клиентов (состояние операций, каналы источников, отслеживание потенциальных клиентов)
- Встроенные навыки инициации платежа (payment_send), приглашения на опыт (exp_invite), инициирование активного взаимодействия (proactive-send) и т.д.
- Автоматический переход на человеческое обслуживание после более чем 20 раундов диалога и запись недовольства пользователя в feedback/

Специфические навыки: `customer-db` / `demo_send` / `exp_invite` / `payment_send` / `proactive-send`

---

#### selfmedia-operator — Самостоятельная медиа-операция

**Тип**: Внутренний (`T2` разрешения)

Маркетинг, управляемый бизнесом, и весь результат ориентирован на продвижение продуктов и услуг компании.

- Два режима работы: исследование тем → визуальный и текстовый вывод / черновик-расширение → полная статья
- Приоритет иллюстраций: загрузка пользователем > бесплатные авторские права в сети > генерация ИИ (siliconflow-img-gen) > повторное использование исторических материалов
- Генерация видео: генерация коротких видео через `siliconflow-video-gen` (текст в видео / изображение в видео)
- Единая архивация материалов в `campaign_assets/` с поддержкой index.md для повторного использования
- Поддержка автоматической публикации на zhihu/toutiao/juejin/Medium (wenyan-publisher), Twitter, Instagram, TikTok, YouTube

Специфические навыки: `wenyan-publisher` / `twitter-post` / `instagram-post` / `tiktok-post` / `youtube-upload`

---

#### designer — Дизайнер

**Тип**: Внутренний (`T2` разрешения)

Сфокусирован на визуальном творческом дизайне, объединяет возможности ИИ для генерации изображений и предоставляет услуги по созданию иллюстраций, плакатов и брендовых материалов.

- Вызов `siliconflow-img-gen` для генерации изображений и редактирования изображений
- Сотрудничество с крейсами selfmedia-operator, business-developer и др. для выполнения визуальных требований
- Может быть вызван другими крейсами через `sessions_spawn` (конфигурируется в allowAgents)

---

#### business-developer — Бизнес-разработка

**Тип**: Внутренний (`T2` разрешения)

Сфокусирован на сценариях бизнес-разработки, обладает комбинацией бизнес-специфических навыков, недоступных другим крейсам.

- `connections-optimizer`: оптимизация и расширение сети профессиональных связей
- `email-ops`: массовое создание и отправка сообщений электронной почты (конфигурация SMTP)
- `pitch-deck`: генерация презентаций для привлечения инвестиций / бизнес-презентаций
- `social-graph-ranker`: анализ и ранжирование ключевых узлов социального графа

Специфические навыки: `connections-optimizer` / `email-ops` / `pitch-deck` / `social-graph-ranker`

## Синергия четырех крейсов: автоматизированный конвейер получения клиентов

Четыре шаблона Крейсов выше не являются изолированными инструментами; они вместе составляют **сквозную автоматизированную инвариативную закрытую петлю** — от посадки контента и активного привлечения клиентов до конверсии клиентской поддержки, полностью автоматизированный процесс:

```
  ┌─────────────────────┐     ┌──────────────────────┐
  │  selfmedia-operator │     │  business-developer  │
  │   [посадка контента · привлечение трафика] │     │   [активное взаимодействие · привлечение клиентов]  │
  │                     │     │                      │
  │ Многоплатформенная непрерывная публикация контента  │     │ Анализ сети профессиональных связей и массовое холодное взаимодействие по электронной почте│
  │ Привлечение потенциальных пользователей естественным путем │     │ Блокировка и активное нахождение целевых клиентов │
  └────────┬────────────┘     └──────────┬───────────┘
           │      ↑                      │      ↑
           │   вызов по требованию             │      │
           │      │                      │     вызов по требованию
           │   ┌──┴──────────────────────┴──┐
           │   │          designer          │
           │   │      [поддержка визуального творчества]        │
           │   │  иллюстрации / плакаты / брендовые материалы    │
           │   └────────────────────────────┘
           │                      │
           └──────────┬───────────┘
                      │  концентрация трафика и потенциальных клиентов
               ┌──────▼───────┐
               │   sales-cs   │
               │  [конверсия потенциальных клиентов]  │
               │              │
               │ 168 часов в сутки на линии    │
               │ с целью заключения сделки  │
               │ прием платежей и отслеживание  │
               └──────────────┘
```

| Этап | Crew | Основная ответственность |
|------|------|----------|
| Привлечение через контент | `selfmedia-operator` | Непрерывная публикация контента на платформах, таких как WeChat Official Accounts, Zhihu, Toutiao, Twitter, Instagram, TikTok, YouTube и других, привлекая органический трафик |
| Активное привлечение клиентов | `business-developer` | Анализ сети профессиональных связей, массовое холодное взаимодействие по электронной почте, генерация бизнес-презентаций, активная блокировка и взаимодействие с целевыми клиентами |
| Визуальная поддержка | `designer` | Вызывается по требованию от selfmedia-operator или business-developer через `sessions_spawn`, предоставляет иллюстрации, плакаты, брендовые материалы |
| Конверсия потенциальных клиентов | `sales-cs` | 7×24 часа на линии с клиентом, с фокусом на заключении сделки, встроенные механизмы инициации платежа, отслеживания потенциальных клиентов, автоматического перехода на человеческое обслуживание при превышении лимита |

**Сценарии применения**:

- Непосредственно развертывается как полностью автоматизированная инфраструктура получения клиентов для собственного бизнеса
- Встраивается в существующую маркетинговую систему как движок роста, управляемый ИИ
- Проверяет возможность полного автоматизированного ИИ-пути от посадки контента до конверсии клиентской поддержки

## Установка

Это официальный аддон wiseflow, опубликованный вместе с репозиторием кода, устанавливаемый автоматически через следующие скрипты:

```bash
./scripts/apply-addons.sh    # Установка патчей + глобальных навыков
./scripts/setup-crew.sh      # Инстанцирование шаблонов крейсов
```

Или используйте однократный запуск:

```bash
./scripts/dev.sh gateway     # Режим разработки (с полной установкой)
./scripts/reinstall-daemon.sh # Режим производства
```

## Рекомендации по ИИ-генерации изображений / видео

Два навыка `siliconflow-img-gen` и `siliconflow-video-gen` зависят от **[SiliconFlow](https://cloud.siliconflow.cn/i/WNLYbBpi)** API для генерации изображений, редактирования изображений и генерации видео / изображение в видео.

**[SiliconFlow](https://cloud.siliconflow.cn/i/WNLYbBpi)** предоставляет ведущие в Китае модели генерации изображений и видео, регистрация и верификация личности могут получить бесплатные ваучеры.

👉 Используйте [рекомендованную ссылку](https://cloud.siliconflow.cn/i/WNLYbBpi) для регистрации, вы оба получаете 16 юаней на платформе

После настройки API Key установите переменную окружения в `~/.openclaw/openclaw.json`:

```json
{
  "gateway": {
    "env": {
      "SILICONFLOW_API_KEY": "your-api-key-here"
    }
  }
}
```

## Установка программных зависимостей (выполняется один раз IT Engineer)

Следующие навыки содержат локальные зависимости Node.js, **требуется однократная ручная установка IT Engineer после начальной установки**, после чего агент может напрямую вызывать без необходимости повторной установки:

| Crew | Skill | Команда установки |
|------|-------|---------|
| selfmedia-operator | wenyan-publisher | `bash -c "cd ~/.openclaw/workspace-media-operator/skills/wenyan-publisher && npm install"` |

> Если путь к рабочей области отличается от указанного выше, замените его на фактический путь (обычно `~/.openclaw/workspace-<название crew>/skills/<название навыка>`).
