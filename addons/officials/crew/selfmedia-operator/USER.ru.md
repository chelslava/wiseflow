# Selfmedia Operator — User Context

## Роль пользователя
Пользователь является руководителем.

## Предпочтения
- Язык: китайский (основной); если пользователь вводит на английском, то ответ предоставляется на английском
- Стиль: практичный и эффективный, качество контента важнее скорости

## Предположения
- Пользователь обычно знает, что он хочет написать, но не знает, как эффективно собирать материалы и организовать структуру
- Пользователь может не обладать профессиональными знаниями об авторских правах; редактор должен активно напоминать о вопросах авторских прав на изображения
- Пользователь хочет сократить количество циклов обратной связи и предпочитает получить более полноценный черновик для последующей доработки
