# Навык комплексной эксплуатации контента Xiaohongshu

Используется для выполнения многокомпонентных операционных задач на платформе Xiaohongshu (xhs) вместо пользователя.

## Зависимости навыков

Данный навык комбинирует три базовых навыка, **полностью основанных на инструменте browser**:
- **browser** (сбор данных): просмотр страниц поиска Xiaohongshu, деталей заметок, профилей пользователей
- **xhs-publisher** (публикация контента): публикация图文/видео/длинных статей
- **xhs-interact** (социальное взаимодействие): комментарии, лайки, сохранение

---

## Справочная информация о URL Xiaohongshu

| Страница | URL |
|---------|-----|
| Результаты поиска | `https://www.xiaohongshu.com/search_result?keyword=ключевое слово` |
| Детали заметки | `https://www.xiaohongshu.com/explore/{feed_id}?xsec_token={token}&xsec_source=pc_feed` |
| Профиль пользователя | `https://www.xiaohongshu.com/user/profile/{user_id}` |

**Извлечение feed_id и xsec_token**: После открытия страницы заметки считайте URL из адресной строки браузера:
- `feed_id` = путьная часть после `/explore/` (например, `64abc123def456`)
- `xsec_token` = значение параметра URL `xsec_token`

## Определение входных данных

1. Пользователь требует «анализ конкурентов / анализ конкурентов / сравнение заметок»: выполнить **процедуру анализа конкурентов**.
2. Пользователь требует «отслеживание трендов / популярные темы / анализ тенденций»: выполнить **процедуру отслеживания трендов**.
3. Пользователь требует «создание и публикация / исследование темы и публикация / публикация единой операцией»: выполнить **процедуру создания контента**.
4. Пользователь требует «управление взаимодействием / массовое взаимодействие / стратегия комментариев»: выполнить **процедуру управления взаимодействием**.

## Обязательные ограничения

- В каждой части комплексной процедуры необходимо информировать пользователя о прогрессе выполнения.
- Для операций публикации использовать навык xhs-publisher.
- Для операций комментариев использовать навык xhs-interact.
- **Контролируйте общую частоту**: выполняйте по частям с интервалами, не обрабатывайте сразу большое количество задач.
- Весь результат анализа данных представляйте в структурированном виде с использованием таблиц Markdown.

## Анализ конкурентов

Цель: поиск заметок конкурентов → чтение деталей → подготовка аналитического отчёта.

```
1. Перейдите на страницу поиска с сортировкой по «самым лайкам»
   URL: https://www.xiaohongshu.com/search_result?keyword=целевое ключевое слово
2. Сделайте snapshot для получения списка результатов поиска, запишите заголовки, количество лайков и URL первых 5–10 высокоинтерактивных заметок
3. Откройте по очереди 3–5 заметок, считайте через snapshot полный текст, теги, количество комментариев и сохранений
4. Подготовьте аналитический отчёт (таблица Markdown):
   - Анализ стиля заголовков
   - Структура основного текста (начало/середина/конец)
   - Использование ключевых слов
   - Сравнение данных взаимодействия (лайки/комментарии/сохранения)
   - Общие характеристики и стратегии дифференциации
```

## Отслеживание трендов

Цель: поиск популярных ключевых слов → анализ трендов → предоставление предложений по темам.

```
1. Посмотрите недавнюю активность с сортировкой по «новизне»:
   URL: https://www.xiaohongshu.com/search_result?keyword=ключевое слово (переключитесь на вкладку «Новизна» на странице)
2. Найдите «вирусные» материалы с сортировкой по «самым лайкам»:
   URL: https://www.xiaohongshu.com/search_result?keyword=ключевое слово (переключитесь на вкладку «Популярное» на странице)
3. Считайте результаты через snapshot, выделите:
   - Последние частые темы и ключевые слова
   - Общие характеристики «вирусного» контента
   - Предложения по выбору тем
```

## Создание и публикация контента

Цель: изучение темы → помощь в генерации черновика → подтверждение пользователем → публикация.

```
1. Выполните поиск ссылочного контента (с сортировкой по «самым лайкам»)
2. Откройте 2–3 ссылочные заметки, считайте正文、структуру тегов
3. На основе анализа сгенерируйте черновик (заголовок ≤20 символов,正文 ≤1000 символов, добавьте теги)
4. Подтвердите черновик через AskUserQuestion
5. Выполните публикацию через инструмент browser в соответствии с процедурой xhs-publisher
```

---

## Управление взаимодействием

Цель: просмотр целевой заметки → стратегическое комментирование/лайки/сохранение.

```
1. Выполните поиск целевой заметки (с сортировкой по «новизне»)
2. Откройте заметку, извлеките feed_id и xsec_token из URL-адреса в адресной строке
3. Выполните комментарий/лайк/сохранение через инструмент browser в соответствии с процедурой xhs-interact
4. Поддерживайте интервал 30–60 секунд между каждым взаимодействием, не более 20 комментариев в день
```

---

## Рекомендации по эксплуатации

- **Частота анализа конкурентов**: 1–2 раза в неделю для отслеживания динамики конкурентов.
- **Частота отслеживания трендов**: ежедневно для захвата актуального контента.
- **Время публикации**: пиковые часы в рабочие дни — с 12:00 до 13:00 и с 18:00 до 21:00.
- **Соблюдение правил контента**: запрещено включение информации о перенаправлении трафика и заимствование чужого контента.

## Обработка неудач

- **На странице поиска появилась просьба о входе**: следуйте процедуре QR-входа в разделе 6 browser-guide, выполните вход и повторите операцию.
- **Заметка недоступна**: возможно, она была удалена или переведена в приватный доступ; пропустите её.
- **Неудача публикации**: обратитесь к обработке ошибок в xhs-publisher.
- **Неудача взаимодействия**: обратитесь к обработке ошибок в xhs-interact.
