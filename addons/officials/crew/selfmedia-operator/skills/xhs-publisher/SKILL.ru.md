# Публикация контента Xiaohongshu

Реализуется через **инструмент browser**, позволяя публиковать заданный контент на платформе Xiaohongshu.

**Предпосылка**: browser должен быть уже выполнен вход в Xiaohongshu. При отсутствии входа следуйте процедуре QR-входа в разделе 6 browser-guide.

---

## Основные правила эксплуатации Xiaohongshu

- **Заголовок** (очень важен): не более 20 символов (счёт UTF-16: иероглифы/полноширинные символы — 1, латиница/цифры — 1 на каждые 2 символа)
- **Текст основного содержания** (очень важен): не более 1000 символов
- **图文 > видео/текст**: для максимального охвата рекомендуется图文-формат
- **Теги**: выбор соответствующих ключевых слов увеличивает охват
- **Запрещено направление трафика**: запрещено включение информации о перенаправлении трафика — является приоритетной зоной борьбы платформы
- **Заявление об оригинальности**: при публикации обязательно выбрать в раскрывающемся списке «Содержимое содержит ИИ-сформированный контент» в разделе «Настройки контента» → «Добавить тип содержимого»

При предоставлении пользователем текстового контента/markdown-пресс-релиза проводится проверка по указанным выше правилам, корректировка несоответствующих частей и добавление в конец основного текста 2-3 соответствующих тегов и шаблона хука платформы Xiaohongshu (см. строгую стратегию публикации в AGENTS.md - Xiaohongshu).

При предоставлении пользователем видео/изображений или простого текстового описания необходимо создать заголовок и основной текст, соответствующие правилам платформы, и добавить в конец основного текста 2-3 соответствующих тега и хук-шаблон платформы Xiaohongshu (см. строгую стратегию публикации в AGENTS.md - Xiaohongshu). Созданный заголовок и основной текст должны быть связаны с предоставленным пользователем содержанием и соответствовать правилам эксплуатации Xiaohongshu.

## Общие ограничения операций browser

- Файл видео должен быть скопирован в `/tmp/openclaw/uploads/` (ограничение песочницы инструмента browser)
- Инструмент `browser upload` может вернуть «ошибку таймаута», но это **не означает неудачи загрузки**! После загрузки проверьте состояние страницы через snapshot (прогресс-бар, текст состояния обработки)
- **Не определяйте неудачу загрузки по `input.files.length == 0`!** Это значение не указывает на ошибку загрузки.
- При ошибке `browser failed: timed out. Restart the OpenClaw gateway ...` **не перезапускайте и не сообщайте об ошибке!** Подождите 30 секунд и продолжите работу на текущей странице. Если операции по-прежнему невозможны, подождите ещё 30 секунд; если проблема не устранена, попробуйте закрыть и перезапустить браузер. Только при ошибке после перезапуска требуется остановить и сообщить пользователю.
- Для мониторинга прогресса загрузки используйте snapshot, а не повторные запросы click

## Определение последовательности действий на основе входных данных

С учётом приоритета:

1. Пользователь указывает «опубликовать длинную статью / написать длинную статью / режим длинной статьи»: переход к **процедуре публикации длинной статьи (процедура C)**.
2. Имеются `заголовок + основной текст + видео (локальный путь)`: переход к **процедуре публикации видео (процедура B)**.
3. Имеются `заголовок + основной текст + изображение (локальный путь)`: переход к **процедуре публикации图文 (процедура A)**.
4. Ежедневная задача HEARTBEAT: переход к **процедуре публикации图文 (процедура A)**.
5. По умолчанию применяется **процедура публикации图文 (процедура A)**.

## Вход в систему публикации

URL-адрес страницы публикации: `https://creator.xiaohongshu.com/publish/publish?source=official`

После перехода на странице в верхней части отображаются три вкладки (точное совпадение по тексту):
- `Загрузить图文` - публикация图文
- `Загрузить видео` - публикация видео
- `Написать длинную статью` - публикация длинной статьи

> **Обработка всплывающих окон**: на странице может появиться всплывающее руководство `div.d-popover`; просто щёлкните за пределами всплывающего окна (например, на пустом пространстве в верхней части страницы), чтобы закрыть его.

## Процедура A: Публикация图文

### Шаг A.1 Переход

```
1. Перейдите на страницу публикации
2. Подождите завершения загрузки страницы (3-5 секунд)
3. Нажмите на вкладку «Загрузить图文»
```

### Шаг A.2 Загрузка изображений

**Важно: Обработка путей файлов**

Инструмент browser upload может обрабатывать только файлы в каталоге `/tmp/openclaw/uploads/`. Если изображения находятся в другом месте, необходимо сначала скопировать их в этот каталог:

```bash
cp /path/to/your/image.jpg /tmp/openclaw/uploads/
```

**Операция загрузки**

```
1. Нажмите кнопку загрузки (или file input)
2. Выполните загрузку изображений через browser upload:
   - selector = input.upload-input
   - paths = ["/tmp/openclaw/uploads/img1.jpg", "/tmp/openclaw/uploads/img2.jpg", ...]
3. После выполнения browser upload подождите 30 секунд
4. Проверьте состояние страницы через snapshot:
   - Отображаются ли предпросмотр/миниатюра изображения
   - Отображается ли на странице текст «редактирование изображения»
   - Отображается ли количество изображений (например, «2/18»)
5. Если при первом snapshot не отображаются миниатюры, подождите ещё 60 секунд и повторите snapshot
6. Повторите проверку максимум 3 раза; только при неудаче трёх проверок считается неудача загрузки
```

### Шаг A.3 Заполнение формы

**Важно: Заголовок и основной текст необходимо вводить отдельно, без использования команды `type`**

Заголовок и основной текст на Xiaohongshu — два независимых поля ввода; управление фокусом browser может направлять команду `type` в поле заголовка, а не в редактор основного текста.

**Правильный способ действия: полная настройка через evaluate**

```
1. Создайте функцию evaluate, которая одновременно устанавливает заголовок и основной текст:
   browser act kind=evaluate fn="() => {
     // Установка заголовка
     const title = document.querySelector('div.d-input input');
     if(title) {
       title.value = 'Заголовок (не более 20 символов)';
       title.dispatchEvent(new Event('input', {bubbles: true}));
     }
     // Установка основного текста
     const editor = document.querySelector('div.ql-editor, [contenteditable], [role=textbox] > div');
     if(editor) {
       editor.focus();
       const sel = window.getSelection();
       const range = document.createRange();
       range.selectNodeContents(editor);
       range.collapse(false);
       sel.removeAllRanges();
       sel.addRange(range);
       document.execCommand('insertText', false, 'Основной текст (одна строка, \n обозначает перенос)');
     }
     return 'done';
   }"
```

**💡 Ключевой момент**: строка параметра fn должна быть преобразована в одну строку (в реальном JavaScript используется \n для переноса), так как многострочная строка приведёт к ошибке разбора evaluate.

**Недопустимые действия (запрещено)**:
- ❌ Использование `type` + `slowly: true` → символы попадут в поле заголовка
- ❌ Использование `fill()` → редактор не распознаёт
- ❌ Отдельное выполнение evaluate дважды → вторая попытка может перезаписать первую

**Ввод тегов**:
```
В конце основного текста нажмите Enter и введите #, затем посимвольно введите ключевые слова:
- После ввода нескольких слов подождите 0,5 секунды и проверьте появление меню подсказки
  (selector: #creator-editor-topic-container .item)
- При появлении меню подсказки нажмите на первый элемент
- При отсутствии подсказки введите пробел для завершения этого тега
- Между каждым тегом ожидайте 0,5-1 секунду (не более 10 тегов)
```

### Шаг A.4 Дополнительные настройки (опционально)

```
Отложенная публикация (опционально, если пользователь не указал, то по умолчанию немедленная публикация):
  1. Нажмите переключатель .post-time-wrapper .d-switch
  2. В .date-picker-container input введите время (формат:2026-04-10 18:00)

Область видимости (опционально, по умолчанию публичная, если пользователь не указал):
  1. Нажмите раскрывающийся список div.permission-card-wrapper div.d-select-content
  2. Выберите цель в div.d-options-wrapper div.d-grid-item div.custom-option
     Доступные значения: Публичный / Только для себя / Только для взаимных друзей

Заявление об оригинальности (опционально, если пользователь не указал, то по умолчанию заявление):
  1. В div.custom-switch-card найдите карточку с текстом «Заявление об оригинальности»
  2. Нажмите переключатель div.d-switch на ней
  3. При появлении диалога подтверждения сначала поставьте флажок协议 checkbox, затем нажмите кнопку «Заявить об оригинальности»
  4. В раскрывающемся списке «Настройки контента» → «Добавить тип контента» выберите «Содержимое содержит ИИ-сформированный контент»
```

### Шаг A.5 Подтверждение и публикация

Публикуйте без вопросов пользователю.

**Проверка**: После публикации убедитесь, что URL перенаправлен на страницу успеха (включает `published=true`), подтвердив успешную публикацию.

```
Перейдите на страницу публикации → Нажмите вкладку «Загрузить видео»

```

```
  selector = .publish-page-publish-btn button.bg-red
```

```
- В раскрывающемся списке «Настройки контента» → «Добавить тип контента» выберите «Содержимое содержит ИИ-сформированный контент»
```

## Процедура C: Публикация длинной статьи

### Шаг C.1 Вход в редактор длинной статьи

```
1. Перейдите на страницу публикации → Нажмите вкладку «Написать длинную статью»
2. Нажмите кнопку «Новое создание» (по текстовому совпадению)
3. Подождите 2 секунды, пока загрузится редактор длинной статьи
```

### Шаг C.2 Заполнение контента длинной статьи

```
Заголовок: textarea[placeholder="Введите заголовок"], кликните и используйте `type` + `slowly: true` для ввода заголовка

Основной текст: div.ql-editor (contenteditable), `type` + `slowly: true` по частям для ввода основного текста

Изображения (опционально): при позиционировании курсора в ql-editor в нужное положение выполняйте загрузку
```

### Шаг C.3 Однократная сборка + выбор шаблона

```
1. Нажмите кнопку «Однократная сборка» (по текстовому совпадению)
2. Подождите 3-5 секунд, пока на странице появится список карточек .template-card
3. Автоматически выберите подходящую карточку шаблона
   - Через snapshot получите заголовок (.template-title) и описание (.template-desc) каждой карточки
   - Определите требуемый тип шаблона (например,图文, видео, длинное изображение) на основе заголовка и описания
4. Нажмите на соответствующую карточку шаблона (.template-card .template-title по текстовому совпадению)
```

### Шаг C.4 Перейдите на страницу публикации для заполнения описания

```
1. Нажмите кнопку «Далее» (по текстовому совпадению)
2. Подождите 3 секунды, страница перейдёт на страницу публикации длинной статьи
3. В div.ql-editor введите описание публикации (резюме, ≤1000 символов)
4. В конце основного текста введите 2-3 соответствующих тега, перед каждым поставьте # и выберите правильный тег из меню подсказки
5. Дополнительные настройки (отложенная публикация, область видимости, заявление об оригинальности) аналогичны процедуре图文
```

### Шаг C.5 Подтверждение и публикация

Публикуйте без вопросов пользователю.

## Обработка ошибок

| Ситуация | Решение |
|---------|---------|
| На странице появилась просьба о входе | Следуйте процедуре QR-входа в разделе 6 browser-guide, выполните вход и повторите операцию |
| Таймаут загрузки изображения (browser upload возвращает ошибку таймаута) | **Игнорировать эту ошибку**, подождите 60 секунд, затем проверьте через snapshot наличие миниатюры на странице |
| Заголовок превышает предел | Автоматически перегенерировать заголовок, соответствующий правилам |
| Основной текст превышает предел | Автоматически сократить |
| Пользователь отменяет публикацию | Обязательно нажать «Сохранить черновик и выйти», не закрывать напрямую |
| Меню подсказки тегов не появляется | Введите пробел для завершения текущего тега и перехода к следующему |
