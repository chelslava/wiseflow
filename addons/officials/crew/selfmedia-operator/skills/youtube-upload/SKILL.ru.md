# Загрузка YouTube Shorts

## Общие ограничения

- Файл видео должен быть скопирован в `/tmp/openclaw/uploads/` до загрузки (ограничение песочницы инструмента browser)
- Инструмент `browser upload` может вернуть «ошибку таймаута», но это **не означает неудачи загрузки**! После загрузки проверьте состояние страницы через snapshot (прогресс-бар, текст состояния обработки)
- **Не определяйте неудачу загрузки по `input.files.length == 0`!** Это значение не указывает на ошибку загрузки.
- При ошибке `browser failed: timed out. Restart the OpenClaw gateway ...` **не перезапускайте и не сообщайте об ошибке!** Подождите 30 секунд и продолжите работу на текущей странице. Если операции по-прежнему невозможны, подождите ещё 30 секунд; если проблема не устранена, попробуйте закрыть и перезапустить браузер. Только при ошибке после перезапуска требуется остановить и сообщить пользователю.
- При вводе заголовка и описания используйте `type` + `slowly: true`, а не `fill()`
- Для мониторинга прогресса загрузки используйте snapshot, а не повторные запросы click

## Последовательность действий

```
1. cp <video_file> /tmp/openclaw/uploads/video.mp4

2. Перейдите на https://studio.youtube.com
   Подтвердите загрузку интерфейса управления каналом (не страницы входа)

3. Перейдите на https://www.youtube.com/upload
   Ожидание появления диалога загрузки ( TIMEOUT: 15s)

4. Загрузите /tmp/openclaw/uploads/video.mp4
   Опрос с интервалом в 15 сек через snapshot до исчезновения прогресс-бара или появления надписи "Processing"
   ( TIMEOUT: 300s — большие видео могут занимать несколько минут)

5. Заполните заголовок (макс. 100 символов)
   Заполните описание и добавьте теги

6. Выберите "Нет, это не для детей"

7. Нажмите "Далее" — подождите 3с
   Нажмите "Далее" — подождите 3с
   Нажмите "Далее" — подождите 3с (переход на страницу видимости)

8. Выберите видимость: Публичный / Неlisted / Запланированный

9. Нажмите "Опубликовать" (или "Сохранить")
   Ожидание появления диалога подтверждения или надписи "Ваше видео опубликовано" ( TIMEOUT: 30s)

10. Перейдите на https://studio.youtube.com
     Извлеките URL видео из первой строки в списке видео
     Сообщите пользователю URL
```

## Источник метаданных

Используйте `.json`-файл из `shorts-compose` для заголовка, описания и тегов:

- `title` → обрезать до 100 символов
- `description` + `tags` → добавлять теги в конец описания как `#тег1 #тег2`

## Обработка ошибок

| Проблема | Решение |
|---------|---------|
| Отображение страницы входа | Сообщить пользователю о необходимости повторного входа в браузер |
| Видео не распознано как Shorts | Проверить соответствие длительности (≤60с) и соотношения сторон (9:16) требованиям |
