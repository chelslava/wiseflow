Поместите каталоги аддонов здесь для их автоматической загрузки через `scripts/apply-addons.sh`.

Каждый подкаталог рассматривается как один аддон (идентифицируется by его манифестом `addon.json`).
Подкаталоги этого каталога **игнорируются в git** — сторонние аддоны не отслеживаются этим репозиторием.

## Аддон против базовой wiseflow

wiseflow использует двухуровневый механизм расширения:

- **Базовая wiseflow** (`patches/` + `skills/`): применяется безусловно при каждом запуске `apply-addons.sh`, действует на все аддоны и крейсы. Включает патчи кода (`patches/*.patch`) и глобальные навыки по умолчанию (`skills/`).
- **Аддон** (`addons/*/`): накладывается поверх базы, предоставляя дополнительные глобальные навыки (`skills/`) и шаблоны Крейсов (`crew/`).

> **Примечание**: аддоны не содержат слой патчей. Если вам нужно наложить патч на openclaw, поместите patch в `patches/` в корне проекта, а не внутрь аддона.

## Установка аддона

```bash
git clone https://github.com/some-org/some-addon.git addons/some-addon
./scripts/apply-addons.sh
```

- Привязку к правильной версии OpenClaw (`openclaw.version`)

- Двухуровневый механизм загрузки (навыки → крейсы)
- Локальную разработку и рабочий процесс тестирования
- Как опубликовать и попасть в маркетплейс
