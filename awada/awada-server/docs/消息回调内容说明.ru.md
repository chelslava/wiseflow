# Пояснение содержания обратного вызова сообщений

### Описание интерфейса обратного вызова сообщений

### Примечание
- В настоящее время поддерживается
    - HTTP-обратный вызов: Сообщение будет отправлено через HTTP-адрес обратного вызова, настроенный в интерфейсе подписки на сообщения.
- Тип обратного вызова (data[].cmd)
    - 11016, Сообщение об изменении состояния учетной записи
    - 20000, Асинхронное сообщение API
    - 15500, Системное сообщение WeChat
    - 15000, Обычное сообщение WeChat

### Сообщение об изменении состояния учетной записи
#### Заголовок сообщения об изменении состояния учетной записи
> cmd=11016
#### Ответ на сообщение об изменении состояния учетной записи
```
{
    "code": 0,
    "data": [
        {
            "TenantId": 0,
            "guid": "a3318ad6-5544-4a4f-a1bb-2aa667b2ipad",
            "userId": "1688*****804",
            "requestId": "901efcada57ff16a469411b3e7f1b009",
            "customParam": "",
            "cmd": 11016,
            "msgServerId": 0,
            "msgType": 0,
            "msgUniqueIdentifier": "901efcada57ff16a469411b3e7f1b009",
            "senderId": 0,
            "seq": 1759125951405848,
            "timestamp": 1759125951,
            "msgData": {
                "guid": "a3318ad6-5544-4a4f-a1bb-2aa667b2ipad",
                "msg": "Вход в систему выполнен успешно",
                "code": 11001, // Состояние учетной записи, см. таблицу ниже
                "status": 2, // Состояние QR-кода 0 и -1 - в автономном режиме 1 - QR-код просканирован, ожидание подтверждения 2 - в онлайн-режиме 3 - сбой входа 4 - пользователь отменил вход 10 - QR-код просканирован, подтверждение, ожидание ввода 6-значного кода 
                "serverReboot": false // Флаг перезапуска сервиса / обновления в горячем режиме (функция объединена с горячим исправлением)
            }
        }
    ],
    "msg": "Успех"
}
```

|Код msgData.code|Описание|
| -- | -- |
|11001|Вход в систему выполнен успешно|
|11002|Выход из системы выполнен успешно|
|11013|Обновление сессии не удалось|
|11017|Учетная запись заблокирована с другого устройства|
|11022|Пользователь вышел из системы вручную на телефоне, отозвав разрешение на устройство|
|11023|Обнаружена аномалия в среде учетной записи, повторно войдите в систему для использования|
|11024|Срок действия входа в систему истек, please перейдите на вход в систему|
