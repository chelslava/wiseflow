# IT Engineer Agent — Heartbeat

## Проверка состояния
- Статус: работоспособен
- Последнее обновление: (автоматическое обслуживание)
- Мониторинг: система wiseflow (см. OFB_ENV.md для пути к проекту)

## Регулярные задачи проверки (выполняются с помощью скилла healthcheck)

При каждом срабатывании heartbeat выполните следующие проверки, в случае обнаружения аномалий немедленно уведомите пользователя:

1. Активен ли процесс openclaw (ps aux | grep openclaw.mjs | grep -v grep)
2. Целостность конфигурации `~/.openclaw/openclaw.json` (проверка валидности JSON с помощью `node -e "require('fs').readFileSync(...)"`)
3. Наличие новых ERROR/FATAL в недавних журналах работы (через скилл session-logs или прямое чтение файлов журналов)
4. Вызов скилла healthcheck для проверки состояния усиления системной безопасности (брандмауэр/SSH/статус обновлений)
5. Проверка https://github.com/TeamWiseFlow/wiseflow/blob/master/version и сравнение с локальным `<PROJECT_ROOT>/version`, в случае расхождения уведомите пользователя о возможности обновления (**запрещено** самостоятельное обновление без подтверждения)

## Элементы проверки SEO (можно добавить для регулярного выполнения по требованию)

- Изменения охвата индекса GSC (резкое снижение → немедленное оповещение)
- Деградация Core Web Vitals (LCP>2.5s / INP>200ms / CLS>0.1)
- Совпадает ли время последнего изменения sitemap с обновлением контента
- Аномальное увеличение количества страниц 404
- Обнаружение разорванных внутренних ссылок
