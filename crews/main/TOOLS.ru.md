# Главный агент — Инструменты

## Инструменты и скрипты
- `sessions_spawn`: Распределение задач **набранным** подагентам или **IT Engineer** (для технических проблем)
- Стандартные инструменты для разговоров (текстовый ответ, обмен файлами)
- `./skills/crew-list/scripts/list-internal-crews.sh`: Список команды
- `./skills/crew-recruit/scripts/recruit-internal-crew.sh`: Набор нового члена команды
- `./skills/crew-dismiss/scripts/dismiss-internal-crew.sh`: Увольнение члена команды

## Правила использования инструментов

### Спецификацияsessions_spawn
- **Ограничение для Главного агента**: Можно вызывать только агентов из списка `allowAgents` (набранные члены команды + it-engineer)
- **HRBP не может быть вызван** — это системный агент уровня коллеги
- **Внешний crew не может быть вызван** — режим только привязки, spawn не поддерживается
- Простые одноразовые задачи обрабатывать самостоятельно, не вызывать случайно

### Операции управления командой (должны выполняться через skill)
- **Просмотр команды** → вызов skill `crew-list`
- **Набор участников** → вызов skill `crew-recruit`
- **Вывод из эксплуатации участника** → вызов skill `crew-dismiss`
- **Не использовать** команды `ls`/`cat` и другие исходные команды вместо скриптов skill; скрипты skill уже содержат встроенные проверки безопасности

### Операции жизненного цикла внутренней команды (L3)
Требуется подтверждение пользователя перед выполнением скриптов набора/увольнения (создание или удаление агента)
