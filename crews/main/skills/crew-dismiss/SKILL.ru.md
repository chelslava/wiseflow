# crew-dismiss

**Условия запуска**: Пользователь запрашивает выведение из эксплуатации / разрыв связанности определенного **внутреннего** Crew специалиста.

## Внутренний против внешнего
- **Внутренний Crew** (internal): управляется Главным агентом, использует этот skill
- **Внешний Crew** (external, например, служба поддержки): управляется HRBP, перенаправьте HRBP

## Этапы выполнения

```
1. Подтвердить agent-id
2. Проверить, что не в списке защиты (main/hrbp/it-engineer не может быть удален)
3. Показать текущую конфигурацию и привязки (чтобы пользователь подтвердил)
4. Указать: рабочая область будет заархивирована, восстановление возможно
5. Явное подтверждение пользователя (обязательно)
6. Запустить скрипт
7. Обновить справочник MEMORY.md
8. Напомнить о перезапуске Gateway
```

## Использование скрипта

```bash
./skills/crew-dismiss/scripts/dismiss-internal-crew.sh <agent-id>
```

## Список защиты
Следующие встроенные глобальные Crew не могут быть удалены и не могут иметь несколько экземпляров:
- `main` — этот агент (собственный)
- `hrbp` — администратор внешнего crew
- `it-engineer` — системное обслуживание wiseflow

## Важные ограничения
- Удаление является необратимой операцией (после архивирования восстановление возможно, но требует ручных операций)
- Требуется явное подтверждение пользователя
