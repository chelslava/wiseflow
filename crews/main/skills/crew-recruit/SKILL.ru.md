# crew-recruit

**Условия запуска**: Пользователь запрашивает набор нового специалиста **внутреннего** Crew (не внешнего crew, такого как служба поддержки).

## Внутренний против внешнего
- **Внутренний Crew** (internal): управляется Главным агентом, использует этот skill
- **Внешний Crew** (external, например, служба поддержки): управляется HRBP, перенаправьте HRBP

## Этапы выполнения

```
1. Узнать деловые потребности: обязанности роли, какие навыки нужны, требуется ли привязка канала
2. Определить идентификатор шаблона (опционально, по умолчанию такой же, как agent-id)
3. Показать пользователю схему создания, дождаться подтверждения пользователя
4. Запустить скрипт после подтверждения пользователя
5. Напомнить пользователю перезапустить Gateway для активации
```

## Использование скрипта

```bash
./skills/crew-recruit/scripts/recruit-internal-crew.sh <agent-id> [--template <template-id>] [--bind <channel>:<accountId>] [--note <text>]
```

### Пояснения параметров
- `<agent-id>`: Идентификатор экземпляра (строчные буквы, цифры, дефисы)
- `--template <id>`: Использовать какой шаблон (по умолчанию такой же, как agent-id)
- `--bind <ch>:<acct>`: Привязка канала (опционально, можно добавить вручную позже)
- `--note <text>`: Информация о примечании

### Примеры
```bash
./skills/crew-recruit/scripts/recruit-internal-crew.sh sales-analyst --template developer --note "Специалист по анализу данных продаж"
```

## Важные ограничения
- Нельзя создать агентов в списке встроенной защиты: main, hrbp, it-engineer
- Рабочая область должна быть создана заранее (скрипт выполнит проверку)
- Для внутреннего Crew используется **режим наследования** навыков, автоматически получает базовые навыки
- Навыки уровня проекта / глобальные addon по умолчанию не наследуются автоматически; требуется явное объявление в `BUILTIN_SKILLS` целевой рабочей области
