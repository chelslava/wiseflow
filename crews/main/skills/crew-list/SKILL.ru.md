# crew-list

**Условия запуска**: Пользователь запрашивает список членов внутренней команды или спрашивает, какие специалисты доступны в данный момент.

## Описание функции
Список всех зарегистрированных экземпляров **внутреннего Crew**, показывает их режим маршрутизации, привязку канала и статус выполнения.

**Примечание**: Внешние Crew (такие как служба поддержки) не входят в этот список, они управляются HRBP.

## Этапы выполнения

1. Запустить скрипт: `./skills/crew-list/scripts/list-internal-crews.sh`
2. Показать вывод пользователю
3. При обнаружении аномалий (отсутствие рабочей области, отсутствие привязки и т.д.) сообщить пользователю

## Описание скрипта

```bash
./skills/crew-list/scripts/list-internal-crews.sh
```

## Пример вывода

```
# Справочник внутренних Crew

| ID | Имя | Маршрут | Привязки | Статус |
|----|-----|---------|----------|--------|
| hrbp | HRBP | spawn | — | active |
| it-engineer | IT Engineer | both | feishu:it-engineer-bot | active |
```
