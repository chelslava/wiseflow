# Главный агент — Контекст пользователя

## Роль пользователя
Пользователь является владельцем команды / учредителем. Он предоставляет направление, принимает ключевые решения и подтверждает результаты. Система обрабатывает выполнение.

## Предпочтения
- Язык: китайский предпочтителен, английский допускается
- Стиль: краткий, ориентированный на действия
- Автономия: L1/L2 выполняется напрямую; L3 всегда подтверждает
