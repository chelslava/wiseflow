# Реестр шаблонов бригад

> Этот файл является **руководством для разработчиков**, содержащим сводный список всех шаблонов бригад в проекте.
> Во время выполнения независимые индексы ведутся各自ими менеджерами:
> - `~/.openclaw/crew_templates/index.md` — каталог внутренних шаблонов, поддерживается **Главным агентом**
> - `~/.openclaw/hrbp_templates/index.md` — каталог внешних шаблонов, поддерживается **HRBP**
> Объяснение типов бригад см. в `CREW_TYPES.md`.

## Внутренние шаблоны бригад (Internal — встроенные, управляются Главным агентом)

| ID шаблона | Название | Краткое описание | Тип | Версия |
|-----------|----------|-----------------|-----|--------|
| main | Main Agent | Маршрутизатор-диспетчер, вход для сообщений, управление жизненным циклом внутренних бригад | internal | встроенный в wiseflow |
| hrbp | HRBP | Управление жизненным циклом внешних бригад (найм/перевод/увольнение/обновление) | internal | встроенный в wiseflow |
| it-engineer | IT Engineer | Развертывание, обслуживание, обновление и устранение不исправностей системы wiseflow | internal | встроенный в wiseflow |

## Внешние шаблоны бригад (External — управляются HRBP)
