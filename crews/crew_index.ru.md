# Каталог внутренних шаблонов бригад

> Этот файл поддерживается **Главным агентом** и содержит все доступные внутренние шаблоны бригад.
> Объяснение типов бригад см. в `CREW_TYPES.md`.

## Встроенные шаблоны (Built-in, предоставляемые системой wiseflow)

| ID шаблона | Название | Краткое описание | Состояние |
|-----------|----------|-----------------|-----------|
| main | Main Agent | Маршрутизатор-диспетчер, вход для сообщений, управление жизненным циклом внутренних бригад | built-in |
| hrbp | HRBP | Управление жизненным циклом внешних бригад (найм/перевод/увольнение/обновление) | built-in |
| it-engineer | IT Engineer | Развертывание, обслуживание, обновление и устранение неисправностей системы wiseflow | built-in |
