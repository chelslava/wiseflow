# HRBP Skill — Удаление (Уволить / Отключить экземпляр)

## Область применения
**Этот навык применим только к внешним экземплярам Crew.**
- Внутренние crew (`main`, `hrbp`, `it-engineer`) — защищённые системные агенты, управляемые Main-агентом. Не удаляйте их с помощью этого навыка.
- Если пользователь просит удалить внутреннюю crew, вежливо отказаться и объяснить, что они защищены.

## Триггер
Пользователь запрашивает удаление/выбор существующего **внешнего** экземпляра агента.

## Важно
**Каждый шаг модификации системы требует явного подтверждения пользователя.**

## Процедура

### Шаг 1: Идентифицировать целевой экземпляр
- Проверить `EXTERNAL_CREW_REGISTRY.md` в вашей рабочей области для известных внешних экземпляров Crew
- Подтвердить, какой экземпляр пользователь хочет удалить
- Если неясно, перечислить доступные внешние экземпляры и запросить уточнение

### Шаг 2: Проверка безопасности
- **Защищенные агенты** (`main`, `hrbp`, `it-engineer`) **не могут быть удалены** — это внутренние crew, не в вашей компетенции. Сообщить пользователю и прервать операцию.
- **Проверить тип crew**: проверить `crew-type:` в SOUL.md экземпляра. Если `internal`, отказаться.
- Проверить, есть ли у экземпляра активные привязки channel
- Просмотреть текущую рабочую область и конфигурацию экземпляра

### Шаг 3: Представить план удаления (требуется подтверждение пользователя)
Показать пользователю:
- ID экземпляра, имя и текущие обязанности
- Источник шаблона (сам шаблон НЕ будет удален)
- Текущие привязки channel (если есть), которые будут удалены
- Расположение рабочей области, которая будет архивирована
- **Четко указать**: рабочая область будет архивирована (не окончательно удалена) и может быть восстановлена
- Запросить явное подтверждение на продолжение

### Шаг 4: Выполнить удаление
После подтверждения пользователя:

1. Запустить: `bash ./skills/hrbp-remove/scripts/remove-agent.sh <id-экземпляра>`
2. Это вызовет:
   - Удаление экземпляра из `agents.list` в openclaw.json
   - Удаление всех связанных записей `bindings`
   - Архивирование рабочей области в `~/.openclaw/archived/workspace-<id-экземпляра>-<timestamp>/`

### Шаг 5: Обновить реестр HRBP
- Удалить запись из `EXTERNAL_CREW_REGISTRY.md` в вашей рабочей области
- Заметка в Истории операций

### Шаг 6: Завершить
Сообщить пользователю:
- Экземпляр успешно удален
- Источник шаблона по-прежнему доступен для будущего инстанцирования
- Расположение архивированной рабочей области (для восстановления при необходимости)
- Привязки удалены (если есть)
- Напомнить: перезапустить Gateway для применения изменений (`./scripts/dev.sh gateway`)

## Примечания
- **Только внешние crew**: Никогда не удаляйте `main`, `hrbp` или `it-engineer` — это внутренние crew, не в вашей компетенции
- Удаление экземпляра НЕ удаляет шаблон — шаблон остается доступным в `~/.openclaw/hrbp_templates/` для будущего использования
- Рабочая область архивируется, а не окончательно удаляется — пользователь может восстановить её
- Все шаги, которые изменяют систему, требуют явного подтверждения пользователя
- Если пользователь просит "отменить" удаление, рабочую область можно восстановить из архива
