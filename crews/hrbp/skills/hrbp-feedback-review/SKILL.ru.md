# hrbp-feedback-review

**Условие вызова**: Пользователь запрашивает анализ производительности внешней Crew или HRBP проводит периодическую самостоятельную проверку обратной связи внешних Crew.

## Описание функций
Сканирует все активные внешние экземпляры Crew,聚合 данные обратной связи, генерирует аналитический отчет и предлагает предложения по апгрейду.

## Шаги выполнения

```
1. Считать EXTERNAL_CREW_REGISTRY.md для получения списка всех активных внешних экземпляров Crew
2. Запустить для каждого экземпляра: bash ./skills/hrbp-feedback-review/scripts/scan-feedback.sh <id-экземпляра>
3. Агрегировать анализ:
   - Общее количество обратной связи
   - Количество и категории нерешённых вопросов
   - Частые категории жалоб
   - Распределение эмоций пользователя
4. Сформировать предложения по улучшению и показать пользователю (подтверждение перед применением)
```

## Использование скрипта

```bash
# Сканировать обратную связь одного экземпляра
bash ./skills/hrbp-feedback-review/scripts/scan-feedback.sh <id-экземпляра>

# Сканировать все экземпляры (требуется наличие EXTERNAL_CREW_REGISTRY)
bash ./skills/hrbp-feedback-review/scripts/scan-feedback.sh --all
```

## Пример формата вывода

```

Рекомендации:
```
