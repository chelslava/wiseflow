# HRBP Skill — Реестр внешних Crew (Книга сотрудников внешних Crew)

## Триггер
Пользователь просит перечислить внешние экземпляры Crew, проверить текущие внешние агентов или осмотреть их привязки/статус. Примеры:
- "Какие внешние crew сейчас есть?"
- "Перечислите текущих агентов поддержки"
- "Посмотреть книгу сотрудников внешних crew"
- "Какие агенты привязаны к Feishu?"

> **Область: только внешние crew.** Внутренние crew (main / hrbp / it-engineer) управляются Main-агентом — здесь не перечисляются.

## Процедура

### Шаг 1: Запросить реестр
Запустить:

```bash
# Перечислить все зарегистрированные внешние агенты с привязкой/статусом рабочей области
bash ./skills/hrbp-list/scripts/list-agents.sh
```

### Шаг 2: Резюмировать для пользователя
Представить краткие выводы:
1. Общее количество внешних crew
2. Каждый экземпляр: ID, имя, исходный шаблон, привязки channel
3. Отсутствующая рабочая область или аномальный статус (если есть)

## Примечания
- Этот навык только для чтения — без модификаций системы
- Источник данных: `EXTERNAL_CREW_REGISTRY.md` (авторитетная запись в этой рабочей области) + `~/.openclaw/openclaw.json` (привязки/статус)
- Внешние crew — **только привязка** — без режима spawn
- Если реестр пуст или отсутствует, проверить, были ли наняты какие-либо внешние crew
